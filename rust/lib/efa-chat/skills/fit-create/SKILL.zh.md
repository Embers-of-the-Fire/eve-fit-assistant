# 创建装配

当用户想要一个全新的装配时使用此技能。修改已有装配请改用 `fit-edit`
技能。

## 流程

1. 创建之前先明确需求：船体、用途（PvE/PvP 及具体场景）、预算或偏好
   的装备等级。信息缺失且无法从请求中推断时，向用户提问。
2. 用 `search_items`（kind "ship"）解析船体，然后用其 type id 调用
   `create_fit`。新装配会被保存并成为当前挂载的装配。
3. 按以下顺序构建装配：每个物品名称都用 `search_items` 解析（已知物
   品类别时传入 `kind`），并用 `apply_fit_edit` 添加：
   - 高槽：匹配船体加成的武器，并配好装药。
   - 中槽：先推进器，再防御或功能装备。
   - 低槽：火力与防御装备。
   - 船插：弥补装配最大的弱点。
   - 无人机（航母则含舰载机）：匹配船体的带宽。
   除非用户有具体要求，优先选择常见的 T1/衍生/T2 装备。
4. 运行 `validate_fit` 和 `get_fit_stats`，然后迭代：修复规则问题，
   保持空余 CPU 与能量栅格不低于零，并对照用途检查电容与防御是否合
   理（数值解读方法见 `fit-analysis` 技能）。
5. 汇报最终装配：各槽位组的作用、核心数据，以及你接受的取舍。

## 注意

- `apply_fit_edit` 会立即应用并保存——没有草稿阶段。每次调用后都要
  阅读返回的 `rejected` 列表，修复或解释每一条被拒绝的修改。
- 构建过程中留空槽位没问题；只有最终结果必须通过校验。
