# 装配分析

当用户询问其装配好不好、弱点在哪里、或某个数值为什么是这样时，使用此
技能。分析绝不修改装配；当用户想要改动时，切换到 `fit-edit` 技能。

## 流程

1. 用 `get_current_fit` 查看实际装配内容（船体、模块、无人机、植入
   体）。只有当问题涉及技能等级时才传 `include_skills: true`。
2. 用 `get_fit_stats` 获取核心数据。
3. 用 `validate_fit` 检查装配规则问题（CPU/能量栅格超载、槽位不匹配、
   缺少装药等）。
4. 只在需要解释特定装备或属性时，才用 `get_item` / `get_attr` 深入查
   询；`get_attr` 会展示数值背后的加成来源分解。

## 如何解读数据

- 电容：对比峰值回充与峰值消耗。增量为负但不会耗尽，或耗尽时间极长，
  说明电容永动；耗尽时间很短，说明无法长时间运行主动装备。
- 防御：查看各层 EHP 与有效抗性；抗性漏洞（某一种伤害类型的抗性远低
  于其他）是最常见的弱点。
- 火力：不计装填的 DPS 是持续输出；评估总火力时要计入无人机/舰载机
  DPS。
- 装配资源：空余 CPU 与能量栅格决定升级空间；没有空余就无法换装更大
  的装备。
- 机动性：速度与跃迁对准时间决定逃脱和转移能力。

## 输出约定

- 先用一段话总结，然后按严重程度列出问题（规则问题优先），最后给出
  具体建议。
- 每个结论都要有工具结果支撑；引用你依据的数字。
- 不要在此应用任何修改——给出建议，由用户决定。
