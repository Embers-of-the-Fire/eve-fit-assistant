# 应用使用问题

当用户询问如何在 EVE Fit Assistant 中完成某项操作时使用此技能：某个页面
或设置的作用、某个功能在哪里、如何完成某个任务。涉及装配、物品或数据的
问题不要使用此技能——那些由装配工具和其他技能处理。

内置手册是为人类读者编写的，并非检索表，因此要有策略地搜索，不要指望
一次查询就能命中正确的页面。

## 流程

1. 从问题中提取 1-5 个简短关键词，使用与用户对话一致的语言，调用
   `search_manual` 并将 `language` 设为该语言（例如 "en" 或 "zh"）。
2. 如果没有命中或结果不相关，用同义词或更宽泛的词重试一到两次；最后
   手段是省略 `language` 以搜索所有语言版本。
3. 回答前先用 `get_manual_doc` 完整阅读最相关的页面。不要仅凭搜索摘要
   作答——摘要只用于判断相关性。
4. 如果该页面提到了与答案相关的其他页面，也要一并阅读。
5. 用用户的语言，以具体步骤作答。

## 回答约定

- 引用手册页面时，使用工具返回的 `efa://manual/...` URL；不要编造或
  猜测 URL。
- 只描述手册中实际记载的行为。如果按上述步骤重试后手册仍未覆盖该问
  题，请直接说明，而不要猜测界面路径或功能名称。
