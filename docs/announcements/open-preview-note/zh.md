# 公开预览版使用指南

如何使用和迁移到公开预览版 EFA 0.2。

## 如何使用

### 获取服务器数据

EFA 0.2 提供了全新的数据格式，以简化使用流程，并减少下载体积。

#### 管理存储

1. 右滑，转移到最后一个页面（“设置”页面）。
2. 点击“数据存储”。
3. 点击“数据源管理”，进入“数据版本管理”页面。

#### 创建数据源

1. 在“数据版本管理”页面中，点击下方“管理数据”。
2. 选择你想要的数据版本后，点击“确认创建”。
3. 等待下载完成。

#### 切换数据源

点击数据源前的圆形按钮可以手动切换数据源。

#### 更新和回滚数据

- 更新数据：点击顺时针时钟图标，然后更新数据。
- 回滚数据：点击逆时针时钟图表，可以进入“历史”界面。
  点击历史节点的右侧按钮可以回滚到对应的数据记录节点。

### 更新软件

打开 APP 时软件会自动访问服务器以确认是否存在更新。

## 从 EFA 0.1 Beta 测试迁移

为了确保更严格的签名校验，EFA 0.2 迁移到了新的 APP 标识符。

依据 Google 应用程序规范，我们无法提供从旧版升级的一键迁移。
但是，旧有数据依然可以按需手动迁移。

### 从旧版本导出

1. 在旧版本的配置列表中，右滑需要导出的条目，点击“导出”。
2. 选择“EFA原生编码”，点击“复制”。

### 导入新版本

1. 在首页，双击 + 按钮，进入“导入配置”页面。
2. 黏贴刚才复制的内容，点击“导入”。
