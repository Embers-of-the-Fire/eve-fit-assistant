# Open Preview Guide

How to use and migrate to the Open Preview EFA 0.2.

## How to Use

### Acquiring Server Data

EFA 0.2 introduces a new data format to simplify the workflow and reduce download size.

#### Managing Storage

1. Swipe right to navigate to the last page ("Settings" page).
2. Tap "Data Storage".
3. Tap "Datasource Management" to enter the "Checkout Management" page.

#### Creating a Data Source

1. On the "Checkout Management" page, tap "Manage Data" at the bottom.
2. Select the data version you want, then tap "Confirm Create".
3. Wait for the download to complete.

#### Switching Data Sources

Tap the circular button next to a data source to manually switch to it.

#### Updating and Rolling Back Data

- Update data: Tap the clockwise clock icon, then update the data.
- Roll back data: Tap the counterclockwise clock icon to enter the "History" screen.
  Tap the button on the right side of a history node to roll back to that data record node.

### Updating the App

The app will automatically check the server for updates when launched.

## Migrating from EFA 0.1 Beta

To ensure stricter signature verification, EFA 0.2 has migrated to a new app identifier.

Per Google's application policy, we cannot provide a one-click migration from the old version.
However, existing data can still be migrated manually on demand.

### Exporting from the Old Version

1. On the fit list of the old version, swipe right on the entry you want to export, then tap "Export".
2. Select "EFA Native Encoding", then tap "Copy".

### Importing to the New Version

1. On the home screen, double-tap the + button to enter the "Import fit" page.
2. Paste the previously copied content, then tap "Import".
