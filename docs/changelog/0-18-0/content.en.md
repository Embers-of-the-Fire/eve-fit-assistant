# v0.18.0 Release Notes

Fit pages gain a new Environment tab for applying system effects like wormholes, abyssal weather, and storms, and PANIC-class modules can now be activated with proper capital-ship validation.

## Environment Effects

- New Environment tab on fit pages: apply wormhole effects, abyssal weather and hazard clouds, metaliminal storms, and other system effects at selectable strengths
- Add custom buffs and edit their strength freely
- Environment effects are saved with the fit and kept when loading or sharing it

## Capital Modules

- PANIC modules can now be activated on capital industrial ships
- Fit validation now warns when a module requires an active industrial core
