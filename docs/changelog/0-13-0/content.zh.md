# v0.13.0 发布说明

本次更新让配置分享更加顺畅：当平台尚未收录你当前的数据版本时，你可以改用服务器上的最新数据发布配置，而不再直接报错。同时修复了配置视图中出现空白子系统栏，以及第二个及后续舰载机中队属性未计算的问题。

## 配置分享

- 平台尚未收录你当前的数据版本时也可分享配置：经你确认后，将使用服务器上的最新数据重现并发布（数值可能略有差异，稍后重新分享即可用本地数据重新计算）
- 以此方式分享的配置会标注为使用平台最新数据计算
- 分享配置后不再自动在浏览器中打开帖子页面——你可以在对话框中选择查看帖子、复制链接，或直接关闭

## 修复

- 修复未装备子系统的舰船在配置视图中仍显示空白子系统栏的问题
- 修复第二个及后续舰载机中队的属性（如伤害输出）未被计算的问题
