# v1.0.0-beta.4 Release Notes

This beta adds an editable pilot security status to fits, with support for security-status-based CONCORD and AT hull bonuses. It also fixes Cachalot compressor compatibility on Serenity and fills missing game-data translations with English text.

## Fitting

- Set pilot security status (-10 to +5) in a fit's Environment tab, apply it to CONCORD and AT hull bonuses, and preserve it when importing, exporting, or sharing fits

## Fixes

- Fix Cachalot fits on Serenity incorrectly reporting large compressors as incompatible
- Show English text when game data has no translation, rather than leaving the text blank
