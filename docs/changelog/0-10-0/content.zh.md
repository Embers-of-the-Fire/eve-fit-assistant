# v0.10.0 发布说明

本次更新包含以下改动。

## 装配分享

- 通过跨平台深链接分享装配，可直接在应用中打开
- 未安装应用时，分享链接会在浏览器中打开本地化的落地页

## 装备磁贴

- 装备磁贴上放不下的滑动操作会收纳进下拉菜单
- 下拉菜单中的操作按分组显示，以分隔线区分
- 新增批量滑动操作，可同时操作多个装备
- 移除操作固定显示在尾部滑动面板的最外侧
- 调整起始滑动操作顺序为装填、动态、复制

## 物品浏览

- 物品列表按衍生组别与等级排序
- 支持按衍生类别筛选物品

## 应用更新

- 支持后台下载应用更新，并在系统通知中显示下载进度

## 修复

- 修复舰载机发射管校验按单个舰载机而非中队计数的问题
- 修复弹药容量计算中小数尺寸被截断的问题
- 修复更新通知操作导致网页版崩溃的问题
