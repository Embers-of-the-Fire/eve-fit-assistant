# v0.14.0 Release Notes

This release adds full support for mutated drones: apply abyssal mutaplasmids to drone stacks, view the rolled attributes, and keep the rolls when saving or sharing fits. The booster picker is also redesigned, and the website gains a sponsor link and faster page loads.

## Fitting

- Mutate drones with abyssal mutaplasmids: mutate a single stack or all drones of the same type at once, and revert to the standard version anytime
- View a mutated drone's rolled attributes in the item details page; mutation rolls are preserved when fits are saved, loaded, and shared
- New booster picker organized by slot; replacing a booster now only shows boosters that fit that slot

## Website

- New sponsor link in the top navigation and on the front page
- Shared fit pages and other site pages load faster
