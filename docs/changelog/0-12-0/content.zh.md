# v0.12.0 发布说明

本次更新将社区平台带入应用：无需离开应用即可浏览和讨论分享的装配，一键分享自己的装配，并支持在 Linux 上通过系统代理联网。

## 应用内社区平台

- 新增社区板块，可浏览共享装配动态、阅读帖子与评论，登录后即可参与讨论
- 支持按热门舰船或时间范围筛选动态，并可通过搜索按舰船浏览共享装配
- 可将帖子中的装配直接打开到装配视图，导入到自己的工作站
- 上传操作现在会链接到发布指南

## 分享装配

- 可在装配详情页将装配分享到平台
- 可在新建装配对话框中打开该舰船的平台页面，在创建前先看看其他人分享的装配

## 网络

- 在 Linux 上，应用现在会遵循系统代理进行聊天、模型发现和更新检查
