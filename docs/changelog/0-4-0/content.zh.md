# v0.4.0 发布说明

本次更新包含以下改动。

## 植入体

- 植入体套装按系列分组展示，显示本地化名称与套装成员数量
- 新增一键应用整套植入体功能，替换对应槽位的植入体并保留其他槽位
- 修复植入体对跃迁速度的效果被重复计算的问题

## 市场价格

- 显示装配的预估价格，以及已计价与未计价物品数量
- 支持 Serenity 与 Tranquility 市场服务器，并可在设置中选择备用服务器

## 应用更新

- 设置中新增应用更新选项，可选择忽略仅修复问题的更新
- 支持在后台静默下载更新，下载完成后通知并确认安装
- 更新检测现在可以区分修复、次要与大版本更新

## 修复

- 修复应用数据存储位置迁移后图标无法加载的问题
