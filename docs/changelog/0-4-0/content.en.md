# v0.4.0 Release Notes

This release includes the changes listed below.

## Implants

- Browse implant sets grouped by family, with localized names and member counts
- Apply an entire implant set to a fit in one action, replacing implants in matching slots while preserving others
- Fix implant effects being applied twice to warp speed

## Market Pricing

- Show an estimated fit price with priced and unpriced item counts
- Support Serenity and Tranquility market servers, with a fallback server setting

## App Updates

- Add an App Updates section in settings to choose whether to ignore bugfix-only updates
- Optionally download updates silently in the background, with a notification when ready to install
- Update detection now distinguishes bugfix, minor, and major releases

## Fixes

- Fix icons not loading after app data storage relocation
