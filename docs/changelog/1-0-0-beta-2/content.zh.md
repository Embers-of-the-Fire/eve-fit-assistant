# v1.0.0-beta.2 发布说明

舰船详情页新增可交互的 3D 舰船模型，支持旋转与缩放。本次更新还修复了 Android 手势导航的遮挡问题，并补全了缺失的中文翻译。

## 舰船 3D 模型

- 在舰船详情页通过“3D 模型”入口查看交互式模型，可旋转、缩放并重置视角
- 可随时在“含纹理”（完整涂装）与“仅几何”（纯色外形）之间切换，也可在“设置 → 应用设置 → 舰船模型”中设置默认呈现方式
- 模型随游戏数据分发，按需加载；“仅几何”模式仅需下载极少数据

## 修复

- 修复 Android 10 及以上使用手势导航时内容被系统导航区域遮挡的问题
- 补全缺失的游戏物品中文翻译
