# v1.0.0-beta.2 Release Notes

Ship detail pages now feature interactive 3D ship models with orbit and zoom controls. This release also fixes Android gesture-navigation overlap and fills in missing Chinese translations.

## Ship 3D Models

- View interactive 3D models from the 3D Model entry on ship detail pages — rotate, zoom, and reset the view
- Switch between Textured (full paint scheme) and Geometry Only (hull shape with flat colors) on the fly, or set the default under Settings → App Settings → Ship Models
- Models are included in data downloads and load on demand; Geometry Only downloads a fraction of the data

## Fixes

- Fix content being hidden behind the system navigation area on Android 10+ when using gesture navigation
- Fill in missing Chinese translations for game items
