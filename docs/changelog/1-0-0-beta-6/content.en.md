# v1.0.0-beta.6 Release Notes

This beta makes fit editing easier to reverse with undo, redo, and a browsable edit history. It also adds workspace settings for shortcut card styles and column layouts.

## Fit Editing

- Undo and redo fit changes with toolbar buttons or standard keyboard shortcuts
- Open the history panel to review edits, jump directly to any recorded state, or clear the history
- History is retained for each fit during the current app session, including when leaving and reopening the fit

## Workspace

- Choose square or compact shortcut cards, or automatically use compact cards in one column and square cards in multiple columns
- Choose responsive columns, a single-column list, or a two-column layout in App Settings
