# v0.9.0 发布说明

本次更新包含以下改动。

## AI 助手

- 新增内置 AI 聊天助手，与装配引擎联动，支持 OpenAI 兼容、Anthropic 与 DeepSeek 服务商，可使用自己的 API 密钥
- 助手可以读取和分析装配，直接修改装配(装备、无人机、舰载机、植入体和增效剂),并可在对话中创建新装配
- 可在 AI 主页或聊天工具栏提交 AI 助手对话反馈,支持附带对话记录

## 装配

- 新增对反应式装甲增强器的支持
- 装配校验现在会检查舰船资源、无人机与舰载机容量限制以及装备状态限制,并提供清晰的本地化警告
- 装配页面现在显示无人机挂舱与舰载机机库的容量占用

## 存储与安装

- 可在初始化时选择自定义的应用数据存储目录,之后也可在设置中更改或重置,数据会自动迁移
- Windows 安装程序现在支持选择安装目录

## 其他改动

- 在设置与版本页面添加了赞助链接

## 修复

- 修复属性页面中货舱与舱室图标错误的问题
