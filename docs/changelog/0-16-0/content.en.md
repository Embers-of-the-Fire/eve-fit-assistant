# v0.16.0 Release Notes

This release adds search to the item pickers, introduces damage spool-up support for precursor turrets, and shows warp disruption field generator range on module slots.

## Fitting

- Precursor (Triglavian) turrets now support damage spool-up: adjust the spool progress to see DPS anywhere from the first round to fully spooled
- Module slots now show the range of warp disruption field generators
- Search for items in the module, charge, booster, and implant pickers, and when creating a new fit

## Fixes

- Fix an error that could occur when opening or leaving the character page
