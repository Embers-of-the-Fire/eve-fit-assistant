# v0.19.0 Release Notes

This release fixes three fitting issues: duplicated ship skill bonuses, understated ancillary armor repair amounts, and implants assigned to the wrong slots.

## Fixes

- Fix ship skill bonuses applying multiple times to modules that require several skills (such as integrated analyzers on Covert Ops ships), overstating their attributes
- Fix ancillary armor repairers not counting ship bonuses, rigs, overheating, and boosters toward the boosted repair amount when loaded with Nanite Repair Paste
- Fix implants being placed under the wrong slot numbers instead of their designated implant slots
