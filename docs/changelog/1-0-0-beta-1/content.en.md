# v1.0.0-beta.1 Release Notes

Choose between Stable and Testing game data, select an update frequency for Stable, and keep app updates on the matching release channel. A new startup announcement explains the choices and links directly to the channel switcher.

## Game Data and App Updates

- Switch between Stable and Testing game-data channels in Settings → App Settings → Data Updates without deleting local data; app update checks follow the selected channel
- Get new data earlier on Testing, or use Stable for snapshots that have spent at least 24 hours on Testing
- Choose Immediate, Weekly (the default), or Monthly for Stable data updates; Testing always tracks the latest data
- Show a startup announcement explaining both channels, with a direct link to the channel switcher
