# v1.0.0-beta.5 发布说明

舰船 3D 模型现在可以在可选的天空盒环境中渲染，并配有相匹配的场景光照。新的模型环境仍处于预览阶段，显示异常在所难免，欢迎反馈。

## 舰船 3D 模型

- 可为舰船模型选择天空盒环境：默认按舰船种族自动匹配，也可手动选择宇宙、虫洞、深渊或装配间
- 场景光照会随所选天空盒与舰船自动调整

## 已知问题

- 天空盒有一个面缺少贴图：这源于底层 Carbon 引擎的问题，短期内无法修复
- 天空盒贴图质量较低，可能出现错误像素：由 D3D DDS 贴图与渲染引擎之间的未知行为导致
- 天空盒光照目前偏暗：手动光照调整仍在实验中

模型环境仍处于预览阶段，如遇到任何显示异常，欢迎向我们反馈。
