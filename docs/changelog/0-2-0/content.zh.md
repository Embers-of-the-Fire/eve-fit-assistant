# v0.2.0 发布说明

本次更新新增首次使用的欢迎向导、应用内更新检测（含发布说明与直接下载）、公告页面，并重新设计了版本信息页面。数据管理现支持按检出与批量更新，提供版本历史浏览与回退功能；凭借全新的下载管线与改进的缓存机制，数据下载速度与稳定性显著提升。

## 新功能

- 新增首次使用的欢迎向导，数据下载时显示下载速度
- 应用更新：自动检测新版本，在更新对话框中展示版本详情与发布说明，支持直接下载新版本，并提供包含推荐项的手动下载页面
- 新增公告页面，可查看官方通知
- 数据管理：可按检出查看数据更新状态，支持单个或批量更新，并可浏览按服务器区分的版本历史、回退到历史版本
- 重新设计版本信息页面，支持本地化；连续点击应用版本 5 次可启用开发者模式并访问开发者工具
- 新增使用反馈对话框，在持续使用后出现，支持后续操作

## 改进

- 通过高吞吐下载管线、连接池与大文件优先策略，配合更完善的缓存机制，数据下载速度与稳定性显著提升
- 跳过未变更的公告与远程内容的重复下载，减少流量消耗
- 提升应用启动与数据迁移速度
- 存储系统升级至 Schema V2

## 修复

- 修复首次启动时无法检测到新版本的问题
- 修复物品描述中可点击链接无法响应点击的问题
