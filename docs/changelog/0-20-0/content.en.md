# v0.20.0 Release Notes

This release adds an item database where you can browse, search, and sort every item in EVE, right from the workspace.

## Item Database

- Browse all in-game items on the new Item Database page, accessible from the workspace
- Search items by name and filter by category or meta level
- Sort the list by name, type ID, meta level, group, or category, in ascending or descending order
- Tap any item to open its detail page
