# v1.0.0-beta.7 Release Notes

This beta adds presets for all four empire Titan Phenomena Generators and fixes incomplete item search results. It also corrects the prefilled values for several custom system effects.

## Fitting

- Add Amarr, Caldari, Gallente, or Minmatar Titan Phenomena Generator effects to a fit using the new presets

## Fixes

- Fix item searches returning incomplete results, including when matching non-item names hide valid items
- Fix incorrect prefilled values when adding custom Sovereignty, Triglavian, or Pirate Insurgency effects

## Framework Update

- Updates flutter AGP and KGP version, and also the rust compiler version.

**Note**: Framework updates may cause unexpected corner cases, so bugs are expected. Please report if you meet them.
