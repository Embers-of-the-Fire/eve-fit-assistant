# v1.0.0-beta.7 发布说明

本次测试版新增四大帝国泰坦现象发生器预设，并修复物品搜索结果不完整的问题；同时更正了多项自定义系统效果的预填数值。

## 装配

- 通过新增预设，为装配应用艾玛、加达里、盖伦特或米玛塔尔泰坦现象发生器效果

## 修复

- 修复物品搜索结果不完整的问题，包括非物品名称的匹配结果导致有效物品被隐藏的情况
- 修复添加自定义主权升级、三神裔或海盗叛乱效果时预填数值不正确的问题

## 框架更新

- 更新了 Flutter AGP 和 KGP 版本，同时更新了 Rust 编译器版本

**注意**：框架更新可能导致预料之外的边界情况，因此出现错误是在预期之内的。使用过程中如果遇到新的错误，请将其报告。
