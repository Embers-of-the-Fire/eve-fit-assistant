# v0.11.0 发布说明

本次更新包含以下改动。

## 装配快照与分享

- 可为任意装配创建快照，完整记录其配置并用于展示
- 上传装配改为独立的“分享”操作
- 快照内嵌稳定的内容寻址物品图标，确保在各处一致地渲染

## 社区平台

- 全新的[社区平台网站](https://platform.efa-tech.dev/)，用于发布和讨论装配
- 装配帖子直接展示渲染后的装配快照，不再显示原始数据
- 首页重新设计为探索面板，便于浏览分享的装配
- 注册装配链接按装配哈希寻址，并通过边缘缓存加快页面加载
- 可从装配帖子页面直接在应用中打开分享的装配
- 支持在网站和应用中使用邮箱与密码注册、登录账号
- 帖子与上传者账号关联，并支持基于角色的创建与删除管理
- 支持在装配帖子下使用 Markdown 发表评论
- 新增平台反馈渠道，以及双语的法律与安全声明

## 修复

- 修复弹药数量因浮点误差而计算不正确的问题
