# v0.6.0 Release Notes

This release includes the changes listed below.

## Breaking Backport

- List tile anti-scroll level has been reset to closed, which is the default behavior
  in 0.4.0 version.

## User Manual

- Improved navigation and localization throughout the manual
- Full-text search powered by FTS5
- New actions on manual pages for reporting issues, giving feedback, and asking questions

## Fitting

- Capacitor stability bar added to the attribute tab
- Scroll position is now preserved when switching between equipment and character tabs

## Settings

- List tile anti-scroll level is now configurable; the default has been reset to closed
