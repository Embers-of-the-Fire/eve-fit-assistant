# v0.15.0 Release Notes

This release makes language data download on demand: switching the app's language now fetches that language's item names with a one-time download. It also fixes several calculation errors involving command bursts and boosters.

## Languages

- Switching the app language now downloads that language's item names on demand — a one-time download that shows its size and progress and can be retried if it fails
- The app now tells you when a language requires a game data update before it can be used

## Fixes

- Fix command burst charges showing incorrect attributes
- Fix command bursts inflating EHP when combined with damage controls or resistance modules
- Fix boosters sometimes showing wrong attribute values
