# 常见问题

**应用可以离线使用吗？**
可以。完成首次数据下载后，所有功能均在本地运行——浏览舰船、配装以及
已保存的配装都无需网络连接。

**数据下载失败或中断了怎么办？**
重新开始下载即可。应用会在下次启动时自动清理中断的下载，失败的下载
不会留下损坏的数据。见[更新数据](efa://manual/data/updating-data)。

**我的配装保存在哪里？**
配装保存在你的设备本地。应用没有账号系统，也不会向服务器上传任何
内容。

**如何在设备之间转移配装？**
在一台设备上将配装导出为文本，再在另一台设备上导入即可。见[导出配装](efa://manual/sharing/exporting-fits)
与[导入配装](efa://manual/sharing/importing-fits)。

**应用提示要迁移旧数据，这是什么？**
这是一次性迁移，会把旧版本应用保存的配装和角色升级到当前的存储格式。
你的配装会被保留；选择不迁移只会让旧数据保持原样。

**数据更新后似乎出了问题？**
把检出回滚到之前的快照即可——每次更新都会记录在检出历史中。见[检出历史与回滚](efa://manual/data/checkout-history-rollback)。

**T3 驱逐舰的战术模式数值看起来不对？**
战术模式数据由人工维护，可能滞后于游戏更新。见[已知限制](efa://manual/reference/known-limitations)。
