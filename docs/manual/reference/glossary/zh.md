# 术语表

应用与本手册中常用术语的简要说明。

## 配装与槽位

- **配装** — 一套保存好的舰船配置，包含装备、无人机与改装件。见[创建你的第一个配装](efa://manual/getting-started/create-first-fit)。
- **高槽 / 中槽 / 低槽** — 分别用于武器、功能装备以及伤害或防御装备的槽位。见[装备与槽位](efa://manual/fitting/modules)。
- **改装件槽** — 用于永久性舰船改装件的槽位，改装件会消耗校准值。见[装备与槽位](efa://manual/fitting/modules)。
- **子系统槽** — T3 巡洋舰的槽位，所选子系统决定船体最终的高、中、低槽数量。见[装备与槽位](efa://manual/fitting/modules)。
- **服务槽** — 建筑用于克隆等服务装备的槽位。见[装备与槽位](efa://manual/fitting/modules)。

## 装备与模式

- **战术模式** — T3 驱逐舰等舰船可切换的作战形态。见[战术模式](efa://manual/fitting/tactical-modes)。
- **上线 / 激活 / 超载** — 装备的三种状态：已供电运行、正在循环工作、超出额定性能运转。见[超载装备](efa://manual/fitting/advanced/overloading)。
- **被动装备** — 无需激活即可提供加成的装备。
- **伤害构成** — 计算中使用的电磁、热能、动能、爆炸伤害的配比。见[伤害构成](efa://manual/fitting/damage-profiles)。

## 角色与物品

- **角色** — 保存的技能档案，可应用到配装上。见[管理角色](efa://manual/characters/managing-characters)。
- **植入体套装** — 一组带有套装加成的配套植入体。见[植入体与增效剂](efa://manual/fitting/advanced/implants-boosters)。
- **增效剂** — 提供临时加成、可能附带副作用的消耗品。见[植入体与增效剂](efa://manual/fitting/advanced/implants-boosters)。

## 数据与统计

- **数据频道 / 服务器 / 检出 / 快照** — 数据频道提供多个服务器；检出是某个数据快照在你设备上的本地副本。见[频道、服务器与检出](efa://manual/data/channels-servers-checkouts)。
- **有效生命值（EHP）** — 按抗性折算后的总生命值。见[属性与统计](efa://manual/fitting/attributes-stats)。
- **每秒伤害（DPS）** — 每秒造成的伤害量。见[属性与统计](efa://manual/fitting/attributes-stats)。
- **电容稳定** — 电容器能否在所有激活装备持续运转下永不耗尽。见[属性与统计](efa://manual/fitting/attributes-stats)。
