# Known Limitations

A few parts of the app rely on data that cannot be extracted automatically
from the game, so they behave differently from the rest of the game data.

- **Tactical mode data is maintained by hand.** Tactical mode definitions
  cannot be exported from the game's data files, so the app currently
  maintains them manually. After a game update changes tactical modes, mode
  names or attributes may be outdated until the data is patched.
- **Fixes arrive with data updates, not app updates.** Manual patches ship
  together with new data snapshots, so the app currently resolves tactical
  mode issues when you update your checkout. See [Updating Data](efa://manual/data/updating-data).

If a tactical mode looks wrong, update to the newest data snapshot first; if
it is still wrong, please report it so the patch can be corrected.
