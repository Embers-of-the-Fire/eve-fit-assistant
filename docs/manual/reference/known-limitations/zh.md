# 已知限制

应用的少部分数据无法从游戏文件中自动提取，因此这些部分的表现与其他
游戏数据有所不同。

- **战术模式数据由人工维护。** 战术模式的定义无法从游戏数据文件中导出，
  因此应用目前以人工方式维护这部分数据。当游戏更新修改了战术模式后，
  模式名称或属性可能会暂时过时，直到数据补丁更新为止。
- **修复随数据更新发布，而非应用更新。** 人工补丁会随新的数据快照一同
  发布，因此应用目前通过更新检出来修复战术模式问题。见[更新数据](efa://manual/data/updating-data)。

如果发现某个战术模式的数据有误，请先更新到最新的数据快照；若问题仍然
存在，请向我们反馈，以便修正补丁。
