# 反馈与日志

在 设置 → **报告与反馈** 中打开报告页面。页面包含两个标签：**缺陷报告**（标题、概述、复现步骤、预期与实际行为）和**功能建议**（问题、方案、影响）。报告可自动附带应用与设备元数据，便于定位问题。页面顶部的链接图标列出了其他外部反馈渠道。

应用也会不定期询问你的使用体验，你的回答可以直接跳转到对应的报告表单，也可以选择不再提示。

如需随报告附上日志，请先开启[开发者模式](efa://manual/settings/developer-mode)，然后进入 开发者设置 → **收集日志**。按时间范围筛选日志文件（最近 1 小时、24 小时、7 天、30 天或全部），勾选需要的文件后点击分享——应用会将所选日志打包为一个 zip 文件，随报告一起发送即可。
