# 开发者模式

进入 设置 → **版本**，在 2 秒内连续点击 **App Version（应用版本）** 数值 5 次，并在弹出的确认对话框中确认，即可开启开发者模式。版本页面顶部会出现**开发者设置**卡片。

开发者设置提供诊断开关（调试日志、属性调试视图、强制布局列数），以及以下操作：打开远程内容设置、收集日志、清除缓存、清除更新确认记录，以及进入开发者工具的快捷入口。

开发者工具包含频道概览、重启初始化、触发反馈和**重置全部存储**。

> **警告：** 重置全部存储会永久删除所有本地数据——设置、配装、角色、数据检出、远程缓存和日志——并将应用重启回首次使用的引导流程。此操作无法撤销。

开发者界面仅提供英文。日常的缓存与数据清理请参阅[存储管理](efa://manual/data/storage-management)。
