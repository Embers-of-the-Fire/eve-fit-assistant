# Developer Mode

To enable developer mode, go to Settings → **Version** and tap the **App Version** value 5 times within 2 seconds, then confirm in the dialog. A **Developer Settings** card appears at the top of the Version page.

Developer Settings offers diagnostic toggles (debug logging, attribute debug view, forced layout column), plus actions: open remote content settings, collect logs, clear the remote cache, clear the update acknowledgment, and a shortcut to Developer Tools.

Developer Tools contains a channel overview, restart initialization, trigger feedback, and **Reset All Storage**.

> **Warning:** Reset All Storage permanently deletes all local data — settings, fits, characters, checkouts, cached remote data, and logs — and restarts the app into the first-run setup flow. There is no undo.

Developer-mode screens are English-only by design. For normal cache and data cleanup, see [Storage Management](efa://manual/data/storage-management).
