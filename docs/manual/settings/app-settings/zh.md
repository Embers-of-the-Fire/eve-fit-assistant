# 应用设置

应用设置页面（设置 → 应用设置）集中了常规偏好与行为选项，更改会立即生效。

- **常规** — 界面语言、字体缩放，以及带交互控件列表的防误触滚动保护。
- **选择列表** — 选择舰船选择器的分组方式（按类别或按市场分组），以及离开类型列表时返回键的行为（返回上一页或直接退出列表）。
- **数据检出** — 切换可能影响配装的数据检出前，是否显示影响警告。
- **市场** — 当主市场价格服务器不可用时，启用备用服务器。
- **更新** — 可忽略仅修复缺陷的版本，或开启静默更新（后台下载，仅在可安装时提示）。

部分选项旁带有信息按钮，点击可查看更详细的说明。
