# App Settings

The App Settings page (Settings → App Settings) groups general preferences and behavior options. Changes take effect immediately.

- **General** — interface language, font scale, and anti-scroll protection for lists with interactive tiles.
- **Select Lists** — choose how the ship picker groups ships (by category or by market group), and what the back action does when leaving a type list (return to the previous page or exit the list).
- **Checkout** — toggle warnings shown before switching to a data checkout that affects your fits.
- **Market** — enable a fallback market price server used when the primary server is unavailable.
- **Updates** — ignore bugfix-only releases, or enable silent updates that download in the background and only prompt when ready to install.

Some tiles include an info button with a longer explanation of what the option does.
