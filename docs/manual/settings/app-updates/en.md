# App Updates

EVE Fit Assistant checks its release channel for newer app versions. When one is found, an update dialog appears with the new version number, download size, and a "What's New" section rendered from the published release notes.

Tap **Download** to fetch the update directly in the app; you can watch progress, then verify and install without leaving the dialog. You can also copy the download link from the dialog and open it in a browser to download manually — useful if the in-app download fails, in which case the dialog also offers a retry.

The Version page (Settings → Version) has a **Check for Update** card that reports the current status and lets you trigger a fresh check at any time. Full release notes for past versions are available from the Release Notes card on the same page.

If you enable **Silent Update** in [App Settings](efa://manual/settings/app-settings), new versions download in the background and you are only prompted once the download is ready to install.
