# 应用更新

EVE Fit Assistant 会检查发布频道中的新版本。发现新版本时会弹出更新对话框，显示新版本号、下载大小，以及由更新日志渲染的“更新内容”。

点击**下载**即可在应用内直接获取更新，你可以查看下载进度，随后在对话框中完成校验和安装。如果应用内下载失败，对话框提供重试；你也可以点击链接图标复制下载地址，在浏览器中手动下载。

版本页面（设置 → 版本）中的**检查更新**卡片会显示当前更新状态，你可以随时点击手动检查。同一页面的“更新日志”卡片可查看历史版本的完整更新说明。

在[应用设置](efa://manual/settings/app-settings)中开启**静默更新**后，新版本会在后台下载，仅在下载完成可安装时提示你。
