# Version

The Version page (Settings → Version) summarizes app and data information and entry points. At the top an app header shows the app name, version, and build number.

- **Developer Settings** — shown only while [Developer Mode](efa://manual/settings/developer-mode) is enabled; tapping it opens the Developer Settings page.
- **Check for Updates** — shows the current update status (checking, up to date, new version available, and so on); tap it to check for updates manually, or to open the update dialog when a new version is available. See [App Updates](efa://manual/settings/app-updates). This card is not shown on the web.
- **Sponsor Us** — opens the sponsorship page in your browser.
- **Info** — grouped rows with app information (app version, build number, package name) and data information (data schema version, the active data checkout, and the current remote content channel).
- **Release Notes** — opens the announcements list; the number of unread announcements appears as a red badge. Not shown on the web. See [Announcements & Remote Content](efa://manual/pages/content/announcements).

As a hidden extra, tapping the **App Version** value 5 times within 2 seconds and confirming in the dialog enables developer mode. A **Developer Settings** card then appears at the top of the page. See [Developer Mode](efa://manual/settings/developer-mode).
