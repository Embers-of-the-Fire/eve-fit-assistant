# 版本

版本页面（设置 → 版本）汇总了应用与数据的信息和入口。页面顶部是应用头部，显示应用名称、版本号与构建号。

- **开发者设置** — 仅当[开发者模式](efa://manual/settings/developer-mode)开启时显示，点击进入开发者设置页面。
- **检查更新** — 显示当前更新状态（检查中、已是最新、发现新版本等），点击可手动检查更新；发现新版本时点击会打开更新对话框。详见[应用更新](efa://manual/settings/app-updates)。该卡片在网页版中不显示。
- **赞助我们** — 在浏览器中打开赞助页面。
- **信息** — 分组显示应用信息（应用版本、构建号、包名）与数据信息（数据模式版本、当前使用的数据检出、当前远程内容频道）。
- **更新日志** — 打开公告列表，未读公告数量以红色角标显示。该卡片在网页版中不显示。详见[公告与远程内容](efa://manual/pages/content/announcements)。

有趣的是，在 2 秒内连续点击 **App Version（应用版本）** 值 5 次，并在确认对话框中确认，可以开启开发者模式。开启后版本页面顶部会出现**开发者设置**卡片，详见[开发者模式](efa://manual/settings/developer-mode)。
