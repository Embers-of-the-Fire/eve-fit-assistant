# 开发者设置

开发者设置页面（设置 → 版本 → 开发者设置卡片）仅在开启[开发者模式](efa://manual/settings/developer-mode)后出现，未开启时访问会被重定向回首页。该页面面向开发者，界面仅提供英文。

页面分为两组：

**开关** — 诊断与调试选项：

- **Debug Log（调试日志）** — 开启更详细的日志记录，更改需重启后生效。
- **Attribute Debug View（属性调试视图）** — 在属性列表中显示未发布属性及其内部标识。
- **Remote Content Visibility（远程内容可见性）** — 控制“远程内容”入口是否在设置中显示。
- **Force Column Selection（强制列数）** — 覆盖网格的列数。

**操作** — 常用维护入口：

- **Open Remote Content Settings** — 打开[远程内容](efa://manual/pages/settings/remote-content)设置，会先弹出警告确认。
- **Collect Logs** — 打开[收集日志](efa://manual/pages/settings/collect-logs)页面（网页版不显示）。
- **Clear Cache** — 清除远程内容缓存。
- **Clear Update Ack** — 清除更新确认记录，使更新提示重新出现。
- **Preview app update dialog** — 使用当前应用版本预览更新对话框。
- **Developer Tools** — 进入[开发者工具](efa://manual/pages/settings/developer-tools)。

如需关闭开发者模式，请参阅[开发者模式](efa://manual/settings/developer-mode)。
