# Developer Settings

The Developer Settings page (Settings → Version → Developer Settings card) appears only after enabling [Developer Mode](efa://manual/settings/developer-mode); visiting it without developer mode redirects back to the home screen. The page is developer-facing and its UI is English-only.

The page is split into two groups:

**Toggles** — diagnostic and debugging options:

- **Debug Log** — enables more detailed logging; the change takes effect after a restart.
- **Attribute Debug View** — shows unpublished attributes with their internal identifiers.
- **Remote Content Visibility** — controls whether the Remote Content entry appears in Settings.
- **Force Column Selection** — overrides the grid column count.

**Actions** — maintenance entry points:

- **Open Remote Content Settings** — opens [Remote Content](efa://manual/pages/settings/remote-content) settings, after a warning confirmation.
- **Collect Logs** — opens the [Collect Logs](efa://manual/pages/settings/collect-logs) page (not shown on the web).
- **Clear Cache** — clears the remote content cache.
- **Clear Update Ack** — clears the update acknowledgment so the update prompt appears again.
- **Preview app update dialog** — previews the update dialog using the current app version.
- **Developer Tools** — opens [Developer Tools](efa://manual/pages/settings/developer-tools).

To disable developer mode, see [Developer Mode](efa://manual/settings/developer-mode).
