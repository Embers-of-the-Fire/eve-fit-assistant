# 外部反馈渠道

外部反馈渠道页面列出了应用之外的联系方式，按分组排列。从[报告与反馈](efa://manual/pages/settings/report-feedback)页面顶部的链接图标进入。

- **常规** — **GitHub 议题**（在浏览器中打开项目问题页面）、**腾讯表单**（打开反馈表单）、**腾讯表格**（查看反馈数据）。
- **社区** — **QQ 官方群**，点按会把群号复制到剪贴板，再粘贴到 QQ 中搜索加群。
- **安全** — **安全邮箱**（打开邮件客户端，主题已预填）、**安全 QQ**（点按复制号码）。

点按链接项会在浏览器或相应应用中打开对应页面；群号与号码类条目会复制到剪贴板。提交反馈与日志的完整流程见[反馈与日志](efa://manual/settings/feedback-and-logs)。
