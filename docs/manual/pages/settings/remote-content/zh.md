# 远程内容

远程内容设置页面（设置 → 远程内容）用于配置远程内容数据源。该页面属于高级/开发者设置：默认情况下“远程内容”入口不在设置中显示，需要先开启[开发者模式](efa://manual/settings/developer-mode)，再在开发者设置中打开远程内容设置，或开启“在设置中显示远程内容面板”。页面包含三项：

- **在设置中显示远程内容面板** — 控制“远程内容”入口是否出现在设置标签页中。关闭后返回上一页。
- **启用远程内容** — 开启或关闭远程内容的获取。
- **数据源** — 显示当前的源地址（origin URL）与频道。点按可打开编辑对话框，修改源地址或在 **testing（测试）** 与 **stable（稳定）** 频道之间切换。

修改源地址或频道会影响应用从哪里获取数据与更新，请谨慎操作。频道与数据更新详见[更新数据](efa://manual/data/updating-data)，开发者设置入口见[开发者设置](efa://manual/pages/settings/developer-settings)。
