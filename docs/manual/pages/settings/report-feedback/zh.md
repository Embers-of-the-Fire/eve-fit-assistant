# 报告与反馈

报告与反馈页面（设置 → 报告与反馈）用于向开发团队提交反馈。页面包含两个标签：

- **缺陷报告** — 填写标题、概述、复现步骤、预期行为与实际行为。
- **功能建议** — 填写标题、问题、方案、影响，以及可选的替代方案与补充说明。

两个表单底部都有**包含元数据**开关（默认开启），开启后报告会自动附带应用与设备信息，便于定位问题。填好后点击页面底部的提交按钮；提交成功后会显示问题链接，可点击在浏览器中查看。提交失败时会显示错误信息，并列出其他可用的外部反馈渠道。

页面顶部工具栏的链接图标（open in new）会打开[外部反馈渠道](efa://manual/pages/settings/report-external-links)列表。如需随报告附上日志，可先开启[开发者模式](efa://manual/settings/developer-mode)，在 开发者设置 → **收集日志** 中打包日志。完整流程见[反馈与日志](efa://manual/settings/feedback-and-logs)。
