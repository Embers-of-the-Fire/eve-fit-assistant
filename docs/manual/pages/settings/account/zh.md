# 账号

账号页面（设置 → **账号**）用于管理你的 EFA Platform 账号。只有使用平台功能（例如[发布配置](efa://manual/sharing/publishing-fits)）时才需要账号——应用的其他功能无需登录即可使用。

## 未登录

未登录时，页面提供两个入口：

- **登录** —— 使用已有账号的邮箱和密码登录。登录页面还提供**忘记密码？**入口（通过发送到邮箱的验证码重置密码）以及注册入口。
- **注册** —— 使用邮箱和至少 10 个字符的密码创建新账号。应用会向该邮箱发送 6 位验证码，输入验证码即可完成注册；未收到时可以重新发送。

入口下方显示平台的法律与安全声明：EFA Platform 是非官方的社区服务，按“现状”提供，工作人员绝不会向你索要密码或验证码（安全问题请发送至 security@efa-tech.dev）；你的会话令牌仅存储在本设备的操作系统安全存储中，绝不会发送给第三方，退出登录后即被删除。

## 已登录

登录后，页面显示当前账号信息——邮箱、用户 ID 与角色（成员、版主或管理员）——以及以下操作：

- **退出登录** —— 确认后退出当前账号并清除本地会话。
- **注销账号** —— 需要确认并输入当前密码。此操作不可撤销：账号将被匿名化，所有会话立即失效，该邮箱可重新注册。

拥有管理员角色的账号还会看到一个管理占位区域。该区域仅用于验证客户端的角色过滤；实际权限始终由平台 API 强制执行。
