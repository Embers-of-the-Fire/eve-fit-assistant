# 收集日志

收集日志页面（开发者设置 → 收集日志）用于挑选日志文件并分享给开发团队。该页面需要先开启[开发者模式](efa://manual/settings/developer-mode)，网页版中不可用。

页面顶部是**快速筛选**时间范围选项：最近 1 小时、24 小时、7 天、30 天或全部。选择某个时间范围后，在该时间窗口内修改过的日志文件会自动勾选。

中间的列表按修改时间倒序列出所有日志文件，每项显示文件名、修改时间与大小，勾选框决定是否纳入口袋。当前正在写入的 **latest.log** 会标记为“活动”。如果你手动勾选或取消某个文件，筛选会自动切回“全部”。

底部栏显示已选文件的数量与总大小。点按**分享**按钮应用会把选中的日志打包成一个 zip 文件并调起系统分享，你可以把它随[反馈报告](efa://manual/pages/settings/report-feedback)一起发送。日志收集的完整流程见[反馈与日志](efa://manual/settings/feedback-and-logs)。
