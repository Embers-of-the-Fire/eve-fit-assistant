# App Settings

The App Settings page (Settings → App Settings) groups general preferences and behavior options. Changes take effect immediately. Options are organized into sections:

- **General** — interface language (简体中文 or English), font scale (a five-step slider from XS to XL), and anti-scroll protection for lists with interactive tiles (off, weak, medium, or strong).
- **Storage** — the storage root directory. This section appears only on native platforms and is editable only on Windows: tap it to pick a new directory and the app migrates your existing data and restarts; when a custom root is set, a **Reset to default** button appears.
- **Select Lists** — how the ship picker groups ships (by category or by market group), and what the back action does when leaving a type list (return to the previous page or exit the list).
- **Checkout** — whether a warning is shown before switching to a data checkout that affects your fits. Turning this off requires confirmation.
- **Market** — enable a fallback market price server (default, Serenity, or Tranquility) used when the primary server is unavailable. This option does not apply on the web.
- **Updates** — ignore bugfix-only releases, or enable silent updates that download in the background and only prompt when ready to install. These options do not apply on the web.

Some tiles include an info button with a longer explanation of what the option does. See [App Updates](efa://manual/settings/app-updates) for update behavior.
