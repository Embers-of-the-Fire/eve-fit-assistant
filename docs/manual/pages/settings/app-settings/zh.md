# 应用设置

应用设置页面（设置 → 应用设置）集中了常规偏好与行为选项，更改会立即生效。页面按分组列出以下选项：

- **常规** — 界面语言（简体中文或 English）、字体缩放（XS、S、M、L、XL 五档滑块），以及带交互控件列表的防误触滚动保护（关闭、弱、中、强四档）。
- **存储** — 存储位置根目录。该分组仅在原生平台显示，且只有 Windows 上可以编辑：点按可重新选择目录，应用会迁移现有数据并重启；使用自定义目录时会出现**恢复默认**按钮。
- **选择列表** — 选择舰船选择器的分组方式（按类别或按市场分组），以及离开类型列表时返回键的行为（返回上一页或直接退出列表）。
- **数据检出** — 切换可能影响配装的数据检出前，是否显示影响警告。关闭该警告需要二次确认。
- **市场** — 当主市场价格服务器不可用时启用备用服务器（默认、Serenity、Tranquility）。该选项在网页版中不可用。
- **更新** — 忽略仅修复缺陷的小版本，或开启静默更新（后台下载，仅在下载完成可安装时提示）。该选项在网页版中不可用。

部分选项旁带有信息按钮，点击可查看更详细的说明。更新相关行为详见[应用更新](efa://manual/settings/app-updates)。
