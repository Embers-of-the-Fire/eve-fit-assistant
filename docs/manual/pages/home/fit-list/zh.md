# 配置列表

配置标签页显示本机保存的全部配置，按最近修改时间从新到旧排列。可以通过底部导航或左右滑动页面切换到该标签页。

## 列表条目

每个条目显示舰船图标、配置名称、舰船类型名称和最后修改时间。

- **点按**配置以打开装配页面。详见[装配页面](efa://manual/pages/fitting/fit)。
- **长按**配置可查看该舰船的详细信息。详见[物品详情](efa://manual/pages/fitting/item-detail)。
- **向右滑动**条目显示**导出**按钮，点按后打开导出对话框。详见[导出配置](efa://manual/sharing/exporting-fits)。
- **向左滑动**条目显示**删除**按钮；删除前会弹出确认对话框，防止误操作。

## 兼容性警告

如果配置与当前激活的游戏数据不匹配，条目上会显示警告图标，副标题中也会出现对应的提示文字。详见[数据频道、服务器与检出](efa://manual/data/channels-servers-checkouts)。

## 下拉刷新

在列表顶部下拉即可重新读取本地配置。

## 空状态

没有任何配置时，页面会显示创建提示。点按中央的加号按钮或工作台的**创建新配置**快捷入口即可开始。
