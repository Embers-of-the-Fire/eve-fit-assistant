# Workspace

The workspace is the tab shown by default when the app opens. The whole home screen is built from the app shell — an app bar, four tabs, a center button, and the bottom navigation — with the workspace page as its content. Swipe left or right to move between tabs.

## The App Shell

The app bar shows the current tab's title, with a data status indicator on the left — a spinning ring while data loads, a glowing dot when ready, and a warning icon on error.

- **Four tabs** — Workspaces, Fits, Character, Settings. Tap an item in the bottom navigation to switch, or swipe the page left or right.
- **Center button** — the circular plus button docked in the middle of the bottom navigation creates a new fit; **double-tap** it to open the import dialog instead.
- **Bottom navigation** — split into two groups around the center button: Workspaces and Fits on the left, Character and Settings on the right.

## Shortcut Cards

The workspace body is a grid of shortcut cards:

- **Create Fit** — opens the ship browser to start a new fit. See [Creating a Fit](efa://manual/pages/fitting/create-fit).
- **Updates** — browse announcements and version news (native platforms only; a badge appears when there's unread content). See [Announcements](efa://manual/pages/content/announcements).
- **AI Assistant** — opens the AI chat (shown only when the native engine is available). See [AI Hub](efa://manual/pages/ai/ai-hub).
- **Manual** — opens the in-app manual on native platforms; on the web it opens the online manual in a new browser tab. See [Manual Browser](efa://manual/pages/content/manual-browser).
- **Report & Feedback** — submit feedback. See [Report Feedback](efa://manual/pages/settings/report-feedback).
- **Settings** — opens the app settings page. See [App Settings](efa://manual/pages/settings/app-settings).

## Data Update Banner

When newer game data is available, a banner appears at the top of the workspace. Tap **Update** to start downloading it, or close the banner to update later from data settings. See [Updating Data](efa://manual/data/updating-data).

## Version Bump Card

When a new app version is detected, a card appears above the shortcuts showing the new version and how many new items it contains. Tap the card to open the Updates page, or tap the close button to dismiss it.
