# Edit Character

The Edit Character page edits a single skill profile and has two tabs: **Skills** and **Info**. The app bar shows the profile's name, and the icon on the right reflects the save state (a download animation while syncing, a done icon once saved).

## Skills

The Skills tab lists skills grouped by category, with a group filter at the top:

- Tap the top bar to expand the group picker and choose a group to show only its skills; tap the selected group again to clear the filter.
- Each skill has five level pips on the right. Tap a pip to set that level; tap the current level again to reset the skill to zero.
- If a skill has an Alpha clone level cap, the pips above the cap use a different color.
- Tap a skill name to view its details. See [Skill Levels](efa://manual/characters/skill-levels).

## Info

The Info tab edits the profile's name and description:

- **Character name** — required, cannot be empty.
- **Description** — optional, up to 8 lines.

Tap **Edit** to enable the input fields, then **Save** to keep your changes or **Cancel** to discard them.
