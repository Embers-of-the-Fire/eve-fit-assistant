# 编辑角色

编辑角色页面用于编辑一个技能档案，包含**技能**与**信息**两个标签页。顶部栏显示档案名称，右侧的图标表示当前保存状态（保存中显示下载动画，已保存显示完成图标）。

## 技能

技能标签页按分组列出技能，顶部是分组筛选器：

- 点按顶部展开分组选择器，选择一个技能分组可只显示该分组的技能；再次点按选中的分组可清除筛选。
- 每个技能右侧有五个等级圆点，点按圆点即可设置对应的技能等级；再次点按当前等级会把该技能清零。
- 若技能对 Alpha 克隆有等级上限，超过上限的圆点会用不同颜色显示。
- 点按技能名称可查看该技能的详细信息。详见[技能等级](efa://manual/characters/skill-levels)。

## 信息

信息标签页用于编辑档案的名称与描述：

- **角色名称** — 必填，不能为空。
- **备注** — 可选，最多 8 行。

点按**编辑**启用输入框，编辑完成后点按**保存**保存更改，或点按**取消**放弃更改。
