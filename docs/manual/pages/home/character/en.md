# Character

The Character tab manages your skill profiles. A skill profile determines the skill levels used when the fitting page computes attributes, and profiles are split into two groups: built-in profiles and custom profiles.

## Built-in Profiles

Built-in profiles are provided by the app and cannot be edited or deleted, but they can be cloned:

- **All V** — every skill at level V.
- **Alpha Max** — every skill at the highest level an Alpha clone allows.
- **All 0** — every skill at level 0 (untrained).

## Custom Profiles

Use the plus button at the right of the Custom profiles section header to create a new profile. The app opens the [Edit Character](efa://manual/pages/home/character-edit) page automatically, and the new profile is named "New Character" by default.

- **Tap** a profile to open its edit page.
- **Swipe right** to reveal **Copy** and **Edit** actions (built-in profiles only offer Copy).
- **Swipe left** to reveal **Delete**; deletion always asks for confirmation first. Custom profile items show their last-modified time.

## Assigning a Profile to a Fit

On the fitting page you can choose which skill profile a fit uses. See [Managing Characters](efa://manual/characters/managing-characters) and [Assigning a Character to a Fit](efa://manual/characters/assign-character-to-fit).
