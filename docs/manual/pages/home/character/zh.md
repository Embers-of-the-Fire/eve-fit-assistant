# 角色

角色标签页管理你的技能档案。技能档案决定了装配页面计算属性时使用的技能等级，分为内置档案与自定义档案两组。

## 内置档案

内置档案由应用提供，不能编辑或删除，但可以克隆：

- **全 5** — 所有技能均为 V 级。
- **Alpha 最高** — 所有技能达到 Alpha 克隆允许的最高等级。
- **全 0** — 所有技能均为 0 级（未训练）。

## 自定义档案

自定义档案分组右侧的加号按钮用于创建新档案。创建后会自动打开[编辑角色](efa://manual/pages/home/character-edit)页面，档案默认命名为"新角色"。

- **点按**档案进入编辑页面。
- **向右滑动**显示**克隆**与**编辑**操作（内置档案只有克隆）。
- **向左滑动**显示**删除**操作；删除前会弹出确认对话框。自定义档案的条目下方会显示最后修改时间。

## 为配置分配档案

在装配页面可以为每个配置选择使用的技能档案。详见[管理角色](efa://manual/characters/managing-characters)与[为配置分配角色](efa://manual/characters/assign-character-to-fit)。
