# 对话

对话页面是 AI 助手的主要交互界面。从 AI 助手页点 **新对话**,或从聊天记录中点击一段对话进入。若尚未配置 API 密钥与接口地址,页面会显示"尚未配置 AI 助手"提示,点 **前往设置** 可跳转至[AI 助手设置](efa://manual/pages/ai/ai-settings)。

页面顶栏包含:

- **模型选择器**(仅在已配置时显示)— 按钮显示当前模型名称。点击弹出模型列表,可切换已保存的模型、**从服务器获取模型列表**(有 30 秒冷却),或输入**自定义模型**。切换模型不会清空当前对话。
- **新对话** — 清空当前对话并重新开始。
- **历史记录** — 打开[聊天记录](efa://manual/pages/ai/ai-chat-history)。

对话区:

- **消息气泡** — 你的消息显示在右侧(主题色气泡),助手消息在左侧(浅色气泡)。助手消息以 Markdown 渲染,回复过程中末尾会显示光标;消息中的应用内链接(如 `efa://manual/…`)可直接点击打开。
- **工具调用块** — 助手每次调用工具都会显示为可展开的窄条:左侧图标加工具名,运行中显示加载指示,完成后显示对勾。点击可展开查看**输入**(JSON 参数)与**输出**(工具结果)。
- **错误横幅** — 发送失败时显示在输入区上方,包含失败原因与 **重试** 按钮,也可关闭横幅后重新输入。

底部输入区为多行输入框(最多 5 行)和发送按钮;回复期间发送按钮变为加载指示,输入框暂时禁用。

回答问题时,助手可以使用两类工具:

- **手册工具** — 助手可搜索并阅读使用手册文档(`search_manual` / `get_manual_doc`),例如解释"如何导入配装"。手册工具需要所选模型支持工具调用,否则无法使用。
- **配装工具** — 当你在[配装页面](efa://manual/pages/fitting/fit)打开某个配装时,该配装会"附加"到对话:助手可读取当前配装、查看属性与统计、运行配装校验,并通过 `propose_fit_edit` 给出修改建议(`get_current_fit`、`get_fit_stats`、`get_item`、`get_attr`、`validate_fit`)。助手也可以搜索物品、列出并加载你保存的配装(`search_items`、`list_user_fits`、`load_fit`)。

AI 助手仅在原生平台(Android、桌面)可用,Web 版不提供此功能。
