# 公告

公告页列出 EVE Fit Assistant 团队的更新日志与新闻。可通过工作台的**更新动态**卡片进入，或在**设置 → 版本 → 更新日志**中打开（仅原生平台）。公告有两个来源：部分随应用内置，更新的部分则在应用同步时作为远程内容送达。详见[公告与远程内容](efa://manual/data/remote-content-announcements)。

## 阅读公告列表

公告列表由一张张公告卡片组成，每张卡片显示：

- **来源徽标** — 该条公告是应用内置还是远程获取。
- **版本徽标** — 若设置了相关版本，则显示对应的应用版本号。
- **日期** — 公告的发布日期。
- **未读圆点** — 红色圆点标记尚未阅读的公告。
- **警告图标** — 当公告面向比你当前更新的应用版本时显示。

列表上方的操作栏可以一键**全部标为已读**或**全部标为未读**。

下拉列表可刷新公告，获取最新的远程公告。

## 阅读公告详情

点按任意一条公告即可打开详情视图。宽屏下页面采用分栏布局：左侧保留列表，右侧面板显示所选公告的详情；窄屏下详情会替换列表，通过返回按钮回到列表。

详情视图显示标题、发布日期、来源与版本徽标以及正文。较长的公告会分成多页，可通过详情页底部的链接继续阅读。应用其他位置的链接也可以直接打开某条公告，详见[应用内链接](efa://manual/sharing/deep-links)。

暂无公告时页面会显示空状态提示，内容加载失败时会提供重试按钮。
