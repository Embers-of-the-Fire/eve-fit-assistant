# Announcements

The announcements page lists release notes and news from the EVE Fit Assistant team. Open it from the workspace's **Updates** card, or from **Settings → Version → Release Notes** (native platforms only). Announcements come from two sources: some are bundled with the app, and newer ones arrive as remote content when the app syncs. See [Announcements & Remote Content](efa://manual/data/remote-content-announcements).

## Reading the Feed

The feed is a list of announcement cards. Each card shows:

- **Source badge** — whether the entry is bundled with the app or came from a remote source.
- **Version badge** — the app version the entry is about, when one is set.
- **Date** — when the entry was published.
- **Unread dot** — a red dot marks entries you have not read yet.
- **Warning icon** — shown when the entry targets a newer app version than the one you are running.

The action bar above the list lets you mark everything as read or unread at once.

Pull the list down to refresh the feed and fetch any new remote announcements.

## Reading an Announcement

Tap an announcement to open its detail view. On wide screens the page uses a split layout: the list stays on the left and the selected announcement opens in the detail pane on the right. On narrow screens the detail replaces the list, and the back button returns to the feed.

The detail view shows the title, publication date, source and version badges, and the full text. If an announcement is longer than one page, follow the link at the bottom of the detail view to continue reading. You can also open an announcement directly from a link elsewhere in the app; see [In-App Links](efa://manual/sharing/deep-links).

When there are no announcements yet the page shows an empty hint, and if content fails to load it offers a retry button.
