# 手册反馈

手册反馈页提供了两种联系团队的方式：**反馈某个页面的问题**，或**提问**。两种方式都会创建一个 GitHub Issue，提交成功后弹出的对话框会提供链接供你查看。

## 反馈问题

从[手册主题](efa://manual/pages/content/manual-topic)的**反馈本页问题**操作进入反馈表单。表单顶部会显示被反馈的页面（标题与 `/manual/...` 路径），标题字段会自动填入该主题的标题。填写问题描述后提交即可。

## 提问

从[手册浏览](efa://manual/pages/content/manual-browser)或任意[手册主题](efa://manual/pages/content/manual-topic)的问号操作进入提问表单。表单与反馈表单相同，只是没有"反馈的页面"卡片。

## 表单内容

两种表单都包含：

- **标题** — 对问题或疑问的简短概括。
- **详细描述** — 具体内容，必填。
- **包含设备信息** — 开关，开启后会在提交内容中附带操作系统版本与应用版本，帮助我们更快定位问题。这些信息会公开显示在 GitHub Issue 中，如不希望公开可关闭。

提交过程中按钮会变为加载状态并禁用。成功后弹出对话框确认提交，并提供查看所创建 GitHub Issue 的链接；失败时弹出错误对话框说明原因，可稍后重试。

其他反馈渠道详见[反馈与日志](efa://manual/settings/feedback-and-logs)。
