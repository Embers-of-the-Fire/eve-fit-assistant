# Manual Feedback

The manual feedback page lets you get in touch with the team about the manual in two ways: **reporting a problem** with a specific page, or **asking a question**. Both create a GitHub issue; after submitting, a success dialog shows a link so you can view it.

## Reporting a Problem

Open the report form from the **Report an issue** action on a [Manual Topic](efa://manual/pages/content/manual-topic). The page you are reporting is shown at the top of the form with its title and `/manual/...` path, and the title field is prefilled with the topic's title. Write a description of the problem, then submit.

## Asking a Question

Open the question form from the question-mark action in the [Manual Browser](efa://manual/pages/content/manual-browser) or on any [Manual Topic](efa://manual/pages/content/manual-topic). The form is the same as the report form, without the reported-page card.

## The Form

Both forms contain:

- **Title** — a short summary of the problem or question.
- **Description** — the details; required.
- **Include device information** — a toggle that appends your OS version and app version to the submission to help us diagnose issues. These details are publicly visible on the GitHub issue, so leave it off if you prefer.

The submit button is disabled while a submission is in progress and turns into a spinner. On success a dialog confirms the submission and offers a link to the created GitHub issue. If the submission fails, an error dialog explains what went wrong and you can try again.

For other ways to reach us, see [Feedback & Logs](efa://manual/settings/feedback-and-logs).
