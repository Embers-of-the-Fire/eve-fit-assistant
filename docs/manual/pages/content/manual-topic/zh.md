# 手册主题

手册主题是手册中的单个页面。可通过浏览[手册浏览](efa://manual/pages/content/manual-browser)、点按其他主题内的链接，或打开应用内 `efa://manual/...` 深链进入——公告和其他应用内容中的链接可以直接指向某个主题。详见[应用内链接](efa://manual/sharing/deep-links)。

## 阅读主题

页面顶部的面包屑栏显示该主题在手册目录树中的位置，点按任意一级可返回对应文件夹。其下方是主题的标题和简短摘要，之后是页面的完整正文。

正文中的链接遵循应用内链接的规则：指向其他手册主题的链接会在应用内打开，`efa://manual/...` 链接会直接跳转到相应页面。相对链接会在手册内解析，因此始终停留在应用内部。如果链接指向不存在的主题，点按会被忽略，不会产生任何影响。

## 主题操作

顶部栏提供三个操作：

- **反馈本页问题** — 打开反馈表单，并自动将当前页面作为被反馈页面。详见[手册反馈](efa://manual/pages/content/manual-feedback)。
- **在 GitHub 上查看源码** — 在浏览器中打开该页面的源文件。
- **提问** — 打开提问表单。提问方式见[手册反馈](efa://manual/pages/content/manual-feedback)。

如果请求的页面不存在，应用会显示"未找到该页面"提示；手册内容加载失败时提供重试按钮。
