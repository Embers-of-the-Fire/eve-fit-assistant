# 手册浏览

手册浏览页是应用内使用手册的首页。原生平台可通过工作台的**使用手册**卡片进入；网页版该卡片会在浏览器新标签页打开在线手册。手册随应用内置，因此支持离线阅读，并随应用版本一起更新。详见[公告与远程内容](efa://manual/data/remote-content-announcements)。

## 浏览文件夹

手册内容以卡片网格呈现。**文件夹**用于组织相关主题，点按可进入其中的子文件夹；**主题**是可供阅读的各个页面。顶部面包屑栏显示当前所在位置，点按任意一级即可返回对应文件夹。空文件夹会显示提示信息。

## 搜索

顶部栏的放大镜图标会打开搜索面板。输入关键词即可在手册全文中搜索，结果会随输入实时更新。每条结果显示匹配的标题、所在文件夹路径，以及高亮标出匹配词的摘要片段。点按结果即可打开对应主题。详见[手册主题](efa://manual/pages/content/manual-topic)。

## 提问

顶部栏的问号图标会打开**提问**表单，可向团队提交你的问题。详见[手册反馈](efa://manual/pages/content/manual-feedback)。

AI 助手也可以帮你搜索手册，详见[AI 聊天](efa://manual/pages/ai/ai-chat)。
