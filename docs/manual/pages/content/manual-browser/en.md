# Manual Browser

The manual browser is the home of the in-app user manual. Open it from the workspace's **Manual** card on native platforms; on the web the card opens the online manual in a new browser tab instead. The manual is bundled with the app, so it works offline, and it is updated together with app releases. See [Announcements & Remote Content](efa://manual/data/remote-content-announcements).

## Browsing the Folders

The browser shows the manual's contents as a grid of cards. **Folders** group related topics and open further subfolders; **topics** are the individual pages you can read. A breadcrumb bar at the top shows where you are in the tree, and tapping a breadcrumb entry jumps back to that folder. An empty folder shows a hint instead.

## Searching

The magnifier icon in the app bar opens the search sheet. Type a query to search the full text of the manual; results update as you type. Each result shows the matching title, the folder path it lives in, and a snippet with the matched words highlighted. Tap a result to open that topic. See [Manual Topic](efa://manual/pages/content/manual-topic).

## Asking a Question

The question-mark icon in the app bar opens the **Ask a Question** form, where you can submit a question to the team. See [Manual Feedback](efa://manual/pages/content/manual-feedback).

The AI assistant can also search the manual for you; see [AI Chat](efa://manual/pages/ai/ai-chat).
