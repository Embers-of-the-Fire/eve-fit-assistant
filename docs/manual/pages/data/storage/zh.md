# 存储管理

存储管理页面汇总了应用本地游戏数据的占用情况，并提供完整性检查与存储维护操作。进入方式：设置 → 数据 → 存储。

## 概览

概览卡片列出当前所有已安装[检出](efa://manual/data/channels-servers-checkouts)共同占用的数据：

- **文件数** —— 全部索引条目的总数。
- **总大小** —— 全部条目的逻辑大小之和。
- **已下载** —— 已实际出现在磁盘上的文件数量与大小。
- **按需下载** —— 尚未下载、首次使用时才按需获取的文件数量与大小。
- **数据源** —— 当前频道名称与本地世代哈希（截断显示）。
- **最后更新** —— 频道头部元数据的最后同步时间；从未同步过的频道显示"从未同步"。

存在尚未下载的文件时，会显示按需下载的提示；缓存提示说明文件由哪些检出共享。下拉列表即可刷新（RefreshIndicator），刷新会重新统计概览并检查一次更新。

## 数据管理

- **游戏数据（更新）** —— 状态随检查结果变化：点按检查全部检出、"正在检查更新…"、"已是最新"、"新的游戏数据已就绪"（点按更新全部）、"正在更新游戏数据…"、失败（可重试）。详见[更新数据](efa://manual/data/updating-data)。
- **数据源管理** —— 打开[数据版本管理](efa://manual/pages/data/checkouts)，管理本地数据版本。

## 存储操作

- **验证完整性** —— 扫描本地数据，检查文件是否齐全。结果是列出存在缺失文件、缺失清单或部分下载等问题的检出；没有问题则显示"已通过完整性检查"。验证带进度条。
- **修复** —— 验证发现问题后出现。下载缺失文件并修复不完整的数据，完成后报告是否全部修复。
- **清理未引用文件** —— 需确认。扫描本地数据库，删除不再被任何检出引用的孤立文件，完成后显示清理数量。
- **强制同步远程存储** —— 强制重新同步当前频道的世代元数据，完成后显示结果。
- **清除全部存储** —— 需确认。删除所有已下载的数据与 HTTP 缓存，随后应用重新初始化。下次同步需要重新下载全部数据，请仅在数据疑似损坏时作为最后手段使用。

执行任何操作期间都会显示进度条，其他操作暂时禁用。验证、修复、清理都不会影响你的配置、角色或设置。另见[存储空间管理](efa://manual/data/storage-management)。
