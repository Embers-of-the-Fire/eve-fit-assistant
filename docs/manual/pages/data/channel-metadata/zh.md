# 频道元数据

频道元数据页面展示当前数据频道的元数据，用于查看频道、服务器、世代资源与应用发布目录的信息。进入方式：设置 → 数据 → 频道元数据。

页面按四个标签页组织：**概览**、**服务器**、**资源**、**发布**。本地尚无频道数据时，页面显示"暂无数据"提示。若应用配置了多个频道，顶栏会出现**切换频道**按钮（切换图标），可切换查看不同频道的元数据。

## 概览

- **当前频道** —— 正在查看的频道名称。
- **世代** —— 本地世代哈希（截断显示）。
- **同步时间** —— 频道头部元数据的最后同步时间。
- **标签** —— 频道标签（含语言代码）。
- **频道** —— 全部可用频道的名称列表。

该频道从未同步过时，显示"尚未同步"提示。

## 服务器

列出该频道内的服务器数量与列表。每行显示服务器 ID、名称、游戏构建与版本，以及地区、同步状态与分支（若有）。各服务器对应不同的游戏环境（类似 TQ/SISI）。

## 资源

列出世代资源：每行显示 `serverId → 快照哈希`（截断），底部显示条目总数。每个条目对应一个服务器在该世代发布的资源快照。

## 发布

显示发布指针哈希。点击**加载发布索引**从远程获取应用发布目录；加载后显示发布版本号与各安卓工件标识（General、Armv7、Arm64、x64），并可点击**重新加载**。频道无发布数据或尚未同步时，页面会给出相应提示。

关于频道、服务器与世代的概念，详见[数据频道、服务器与检出](efa://manual/data/channels-servers-checkouts)。
