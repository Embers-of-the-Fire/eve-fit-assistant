# 频道总览

频道总览是一个面向开发者的诊断页面，用于查看频道的元数据与同步状态。页面本身仅显示英文，不参与本地化。它通过开发者工具进入：先开启[开发者模式](efa://manual/settings/developer-mode)，然后进入 设置 → 版本 → 开发者设置 → 开发者工具 → 频道总览。

页面按分区展示：

- **Channel** —— 当前的激活频道、世代哈希、同步时间、标签与全部频道名称。尚未同步时显示占位提示。
- **Servers** —— 服务器目录：服务器 ID、名称、游戏构建与版本，以及地区、同步状态与分支；标题显示服务器数量。无目录时提示需先同步或创建检出。
- **Generation Resources** —— 世代资源列表（`serverId → 快照哈希`）与条目总数。
- **Release Info** —— 发布指针哈希；点击 **Load Release Index** 从远程加载发布目录（发布版本与各安卓工件标识），加载失败会显示错误提示。
- **Actions** —— **Refresh from Remote** 重新发现频道并同步当前频道的世代元数据，完成后刷新页面数据。

普通用户如需查看频道信息，应使用[频道元数据](efa://manual/pages/data/channel-metadata)页面；本页面仅用于诊断排查，无需日常使用。
