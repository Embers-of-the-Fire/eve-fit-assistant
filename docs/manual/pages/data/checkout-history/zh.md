# 数据版本历史

数据版本历史页面展示单个检出的完整历史记录（reflog），并支持从一个较早的快照回滚。进入方式：设置 → 数据 → 检出管理 → 点击检出卡片上的历史按钮，或从检出详情面板进入。

若检出的记录已不存在（例如已被删除），页面会提示未找到该检出并提供返回按钮。

## 头部

页面顶部显示：

- **服务器** —— 检出所属的服务器 ID。
- **频道** —— 检出所属的频道。
- **当前哈希** —— 检出现指向的快照哈希（截断）。
- **切换次数** —— 历史记录中的迁移条目总数。

下方显示检出的游戏构建/版本，以及地区、同步状态与分支（若有）。

## 历史记录

历史列表按时间**逆序**排列（最新在前）。每条记录显示：

- **序号** —— 迁移编号（#1、#2 …）。
- **变化** —— 以 `来源 → 目标` 形式显示的哈希（截断）。初始迁移的来源显示为短划线。
- **时间** —— 迁移发生的时间。

每条记录带有徽标：当迁移目标正是检出当前所指向的快照时，显示**当前**（绿色）；初始迁移显示**初始**。

点按记录可展开详细内容：来源哈希、目标哈希，以及游戏构建、版本、作者、描述、资源数量与创建时间（若快照元数据可用）。

## 回滚

每条非当前记录右侧有**撤销**按钮。点击后需确认：确认后检出会恢复到该记录指向的快照。若该检出是当前激活的数据版本，应用会立即改用回滚后的旧数据。回滚安全且可逆，之后可再次更新。详见[检出历史与回滚](efa://manual/data/checkout-history-rollback)。
