# 数据版本管理

[检出](efa://manual/data/channels-servers-checkouts)是下载到设备上的数据快照。数据版本管理页面列出所有本地检出，并支持激活、更新、查看详情、删除与新建。进入方式：设置 → 数据 → 检出管理，或从[存储管理](efa://manual/pages/data/storage)页面的"数据源管理"进入。

没有检出时，页面显示空状态提示。

## 检出卡片

每个检出一张卡片，从左到右包含：

- **激活指示器** —— 圆形的状态指示。激活的检出显示主题色对勾；未激活的检出显示空心圆，点按可将其激活（需确认）。激活的检出为装配器提供全部舰船、物品与技能数据。
- **名称** —— 检出的显示名称。
- **频道** —— 检出所属频道的标签。
- **创建时间** —— 检出记录的时间。

卡片右侧是操作按钮：

- **更新** —— 检查并应用该检出的数据更新，弹出更新进度对话框。详见[更新数据](efa://manual/data/updating-data)。
- **历史** —— 打开[数据版本历史](efa://manual/pages/data/checkout-history)。
- **详情** —— 弹出底部信息面板，显示频道、服务器 ID、快照哈希、创建时间、文件数与总大小，以及已下载与按需下载的数量和大小；面板内也可直接跳转到历史页面。
- **删除** —— 需要确认；删除激活的检出时有额外确认。仅有的一个检出无法删除，删除按钮会被禁用。

## 管理数据（新建检出）

页面底部的**管理数据**悬浮按钮打开创建检出面板：

- 若当前频道尚无世代数据，面板会提示先同步，点击**立即同步**获取频道的世代元数据。
- 从服务器列表中选择一个服务器：每行显示名称、快照哈希、服务器 ID 与游戏构建/版本。选中后从远程加载该快照的元数据——作者、描述、资源数量、创建时间、地区、同步状态与分支。
- 元数据加载完成后，底部**确认**按钮会显示资源数量。点击后弹出进度对话框，依次显示：获取索引 → 下载（带进度条）→ 完整处理。完成后新检出会自动成为激活检出；若有部分文件下载失败，会显示"部分完成"状态，可稍后通过[存储管理](efa://manual/pages/data/storage)页面的验证与修复重新获取缺失文件；严重错误则显示失败状态。

激活检出决定了应用使用的数据版本，有关概念详见[数据频道、服务器与检出](efa://manual/data/channels-servers-checkouts)。
