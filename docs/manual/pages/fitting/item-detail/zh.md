# 物品详情

物品详情页面展示单个物品（舰船、装备、弹药、无人机、技能等）的完整信息。在装配页面点按或长按物品行、在舰船浏览器长按舰船、在配置列表长按配置，或长按技能树中的技能节点，都会打开该页面。

页面标题为物品名称。主体按屏幕宽度采用响应式多栏布局：手机为单栏（用标签页切换），平板两栏，宽屏三栏，各栏默认显示对应位置的标签页。

## 标签页

### 信息

信息标签页自上而下包含：

- **头部卡片** —— 物品图标（叠加科技等级角标）、名称，以及所属科技等级与物品组标签。
- **分类卡片** —— 类型编号、类别、物品组与市场分组。
- **描述** —— 物品的官方描述文字（若有）。
- **特性** —— 舰船特性，按技能分组的加成列表。
- **装配信息** —— 若物品是舰船或子系统，列出高/中/低槽、改装件、子系统与服务设施槽数量；若物品是装备，则显示它所属的槽位类型。

### 动态

仅当物品是配置中的动态（变异）物品时显示。动态标签页用于编辑变异取值：

- 顶部显示**基础物品**与**突变质体**两个标签。
- **重置**按钮将全部属性恢复为基准值；**重新随机**按钮按突变质体的取值范围重新随机所有属性。
- 每个可变异属性占一行：属性名、取值输入框、最小值/当前值/最大值对照，以及当前取值在允许范围内的比例条。输入新值后按提交或让输入框失焦即生效，超出范围的值会被自动夹取到边界。

详见[突变质体与动态物品](efa://manual/fitting/advanced/mutaplasmids-dynamic-items)。

### 属性

属性标签页列出物品的全部属性及其数值。若物品来自配置，数值显示为按角色、战术模式与模块状态计算后的当前值，并通过颜色标示相比基础值的增减。长按某个属性会打开[属性详情](efa://manual/pages/fitting/attribute-detail)页面。

### 技能

技能标签页以树状结构展示使用该物品所需的技能：每个节点显示技能名与所需等级（用五个方块表示），可展开查看前置技能。长按技能节点可查看该技能的详情。
