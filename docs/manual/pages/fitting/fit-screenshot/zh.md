# 配置截图

配置截图页面把当前配置渲染成一张海报式图片，供保存或分享。在[装配页面](efa://manual/pages/fitting/fit)的**杂项**标签页点按**导出图片**即可打开。

## 预览

页面主体是配置的实时预览，采用固定的三栏排布：

- **角色栏** —— 植入体与增效剂。
- **装备栏** —— 战术模式、高/中/低槽、改装件、子系统、服务设施槽、无人机与舰载机。
- **属性栏** —— 舰船信息、电容、武器、资源、防御、杂项与货仓。

预览为只读快照，不提供编辑操作；配置与其计算属性完全加载后才能生成图片。

## 保存与分享

- **保存图片** —— 以 PNG 文件写入应用的下载（或文档）目录，文件名由配置名加时间戳组成。
- **分享图片** —— 通过系统分享面板把图片发送给其他应用或联系人。

图片按设备像素密度以高分辨率渲染，放大或发布后仍保持清晰。关于生成图片的更多说明，参见[配置截图](efa://manual/sharing/fit-screenshots)。
