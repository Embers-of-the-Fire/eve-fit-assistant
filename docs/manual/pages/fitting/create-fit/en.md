# Creating a Fit

The create-fit page is the app's built-in ship browser. Pick a ship to start a new fit from scratch.

To open it, use the **Create Fit** shortcut on the workspace or the circular plus button in the center of the bottom navigation. See [Workspace](efa://manual/pages/home/workspace).

## The Ship List

How the list is organized depends on the **Select List** grouping option in app settings (Settings → App Settings):

- **By category** — expand a ship category (for example frigates, cruisers) into the ship groups it contains, then down to individual ships.
- **By market group** — expand the market tree starting from the Ship market group, drilling down through sub-groups to individual ships.

Expand a group and tap a ship to open the create dialog. Long-press a ship to open its [Item Detail](efa://manual/pages/fitting/item-detail) page. For tips on finding and filtering ships, see [Browsing Ships](efa://manual/getting-started/browse-ships).

## The Create Dialog

After you pick a ship, a dialog appears with:

- **Fit name** — enter a name for the new fit. A default name is suggested that includes the number of existing fits for this ship (for example "New Fit 3"); the name cannot be left empty.
- **Existing fits for this ship** — the dialog also lists other outfits already saved for this ship. Tap one to open it directly, or use the delete button on a row to remove it (deletion always asks for confirmation).

Tap **Confirm** to create the fit and open the [Fitting Page](efa://manual/pages/fitting/fit). Tap **Cancel** to return to the ship list.
