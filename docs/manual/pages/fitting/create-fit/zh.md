# 创建配置

创建配置页面是应用内置的舰船浏览器。通过它选择一艘舰船，命名后即可开始装配。

进入方式：工作台页的**创建新配置**快捷入口，或底部导航中央的圆形加号按钮。详见[工作台](efa://manual/pages/home/workspace)。

## 舰船列表

列表的分组方式取决于应用设置中的**选择列表**分组选项（设置 → 应用设置 → 选择列表）：

- **按类别** —— 从舰船类别（如护卫舰、巡洋舰）展开到该类别下的舰船组，再到具体舰船。
- **按市场分组** —— 从市场分组（如舰船）向下逐级展开子市场分组，再到具体舰船。

展开分组后，点按一艘舰船即可打开创建对话框。长按舰船会打开[物品详情](efa://manual/pages/fitting/item-detail)页面查看该舰船的信息。关于查找与筛选舰船的技巧，参见[浏览舰船](efa://manual/getting-started/browse-ships)。

## 创建对话框

选中舰船后弹出的对话框包含：

- **配置名称** —— 输入新配置的名称。默认会预填一个名称，其中包含这艘舰船现有配置的数量（例如"新配置 3"），名称不能为空。
- **该舰船的已有配置** —— 对话框列出这艘舰船已保存的其他配置，点按可直接打开；条目右侧的删除按钮可删除对应配置，删除前会先确认。

点按**确定**创建配置并打开[装配页面](efa://manual/pages/fitting/fit)，点按**取消**则回到舰船列表。
