# 主页与配装列表

主页是应用的起始页面，上方是快捷入口——新建配装、公告、本手册、问题反馈和设置，下方是你保存的配装列表。

## 配装列表

配装按最近修改时间排序，下拉可刷新列表。

- **点按**配装可进入装配页面。
- **长按**配装可查看该舰船的详细信息。
- **向右滑动**可导出配装。
- **向左滑动**可删除配装，删除前会弹出确认对话框。

如果配装与当前使用的游戏数据不匹配，条目上会显示警告图标（详见[数据频道、服务器与检出](efa://manual/data/channels-servers-checkouts)）。

## 新建配装

点按主页的**新建配装**打开舰船浏览器，选择一艘舰船并确认即可开始新的配装。详见[创建你的第一个配置](efa://manual/getting-started/create-first-fit)。

## 数据更新横幅

当有更新版本的游戏数据时，主页顶部会出现横幅。点按**更新**即可下载新数据，或关闭横幅、稍后在数据设置中更新。详见[更新数据](efa://manual/data/updating-data)。
