# First-Run Setup

On first launch, the app walks you through a setup wizard before it becomes usable. You can skip the wizard at any step with the Skip button and finish setup later from settings.

## Steps

1. **Language** — pick the display language. The language detected from your device is marked with a badge.
2. **Channel** — pick a data channel. Channels are separate feeds of game data; the recommended default channel is marked. See [Channels, Servers & Checkouts](efa://manual/data/channels-servers-checkouts) for details.
3. **Server** — pick one or more game servers to download data for. The app shows each server's game build and version, plus the total download size, and asks you to confirm before downloading.
4. **Provisioning** — the app downloads the selected data and creates a local checkout. Keep the app open until the progress bar finishes.

When provisioning completes, tap anywhere on the screen to enter the app. If the download fails, you can go back or retry. You can add more servers or switch data later from the data settings.
