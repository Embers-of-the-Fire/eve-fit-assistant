# 首次启动设置

首次启动应用时，会进入一个设置向导，完成后应用才能正常使用。任何步骤都可以点"跳过"按钮跳过，之后在设置中再完成配置。

## 步骤

1. **语言** —— 选择显示语言。与你设备语言一致的选项会有提示标记。
2. **数据频道** —— 选择一个数据频道。频道是互相独立的游戏数据源，推荐的默认频道会有标记。详见[数据频道、服务器与检出](efa://manual/data/channels-servers-checkouts)。
3. **服务器** —— 选择一个或多个要下载数据的游戏服务器。界面会显示每个服务器的游戏版本与构建号，以及总下载大小，下载前需要确认。
4. **数据准备** —— 应用下载所选数据并创建本地数据副本。请保持应用在前台，等待进度条完成。

数据准备完成后，点按屏幕任意位置即可进入应用。如果下载失败，可以返回上一步或重试。之后还可以在数据设置中添加更多服务器或切换数据。
