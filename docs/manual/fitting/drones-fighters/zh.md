# 无人机与舰载机

拥有无人机挂仓的舰船在装配页面会显示**无人机**标签页；航空母舰等拥有
舰载机发射管的舰船则显示**舰载机**标签页。点击 **+** 按钮添加条目，
然后滑动条目行设置数量——左侧为 **x1** / **x5**（舰载机为**补满**），
右侧为 **+1** / **-1** / **删除**；一侧操作超过两个时，多余操作折叠进
**更多**菜单，**删除**固定在最外缘。清空按钮可一键清空整个挂仓。

无人机受两项限制：挂仓容积，以及带宽——带宽决定同一时间能放出多少
无人机。切换条目状态可将无人机标记为出战（在太空中、计入伤害）或
停放在挂仓中。

舰载机标签页的标题栏会分别统计轻型、支援与重型舰载机中队相对于船体
各类发射管的占用情况，以及发射管总数——超出限制时计数会变为红色。
舰载机始终按出战状态计算。

无人机与舰载机的伤害如何计入攻击数值，见[属性与统计](efa://manual/fitting/attributes-stats)。
