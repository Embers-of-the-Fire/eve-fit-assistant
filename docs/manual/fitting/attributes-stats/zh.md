# 属性与统计

**属性**标签页展示当前配置计算出的各项统计：

- **攻击** —— 总每秒伤害（DPS）与单轮齐射伤害，按炮台、发射器以及
  无人机或舰载机分别列出。
- **防御（HP）** —— 护盾、装甲与结构的耐久值、各类抗性、有效生命值
  （EHP）以及主动修复速率。
- **电容** —— 电容容量、回充速度，以及配置是否电容永动；若不能永动，
  会显示全装备运转下的耗尽时间。
- **资源** —— 本配置的 CPU、能量栅格与校准值占用。
- **导航与锁定** —— 航速、跃迁准备时间、跃迁速度、信号半径、锁定距离
  与扫描分辨率（位于杂项面板）。
- **货仓** —— 剩余货仓容量，以及整套配置的估价。

所有数值都按当前所选角色的技能计算，在角色标签页切换角色后结果会
随之变化。

防御与 EHP 数值基于设定的来袭伤害概况——详见[伤害概况](efa://manual/fitting/damage-profiles)。
可切换模式的舰船在切换[战术模式](efa://manual/fitting/tactical-modes)时
这些数值也会改变。
