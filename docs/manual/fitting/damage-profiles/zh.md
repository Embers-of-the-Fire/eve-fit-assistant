# 伤害概况

防御与 EHP 数值取决于来袭的是什么伤害。伤害概况设定配置所承受的电磁、
热能、动能与爆炸伤害的比例，防御面板会将其与你的抗性结合计算。

修改方法：打开属性标签页，在防御（HP）面板中找到伤害概况行，点击设置
图标，在对话框中选择预设：

- **通用** —— 均匀分布（四种伤害各占 25%）或单一纯伤害类型。
- **武器弹药预设** —— 对应真实弹药组的概况，如频率晶体、混合弹药、
  射弹弹药、导弹与炸弹，适合在已知特定 NPC 或对手的伤害类型时使用。

所选概况会随配置保存并显示在防御面板中，其他打开该配置的人看到的也是
相同伤害构成下的防御数值。

这些数值所影响的统计面板，见[属性与统计](efa://manual/fitting/attributes-stats)。
