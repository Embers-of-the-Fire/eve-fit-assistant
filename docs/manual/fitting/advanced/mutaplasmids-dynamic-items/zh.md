# 突变等离子体与动态物品

由突变等离子体生成的物品（深渊装备）的属性与其基础物品不同。在配置中打开
该物品的详情页并切换到**动态**标签，即可查看基础物品、所用的突变等离子体
以及每一项变异属性。

每个属性行都会显示基础数值与变异系数，让你准确了解本次变异的结果。配置中
所有数值计算都使用变异后的属性。

点击**重掷**可在突变等离子体的最小/最大范围内重新随机所有属性，点击
**重置**可将所有属性恢复为基础数值。你也可以手动编辑单个属性的系数，以
模拟某个特定的变异结果。

关于装配基础，请参见[装备与槽位](efa://manual/fitting/modules)。
