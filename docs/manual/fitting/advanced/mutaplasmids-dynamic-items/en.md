# Mutaplasmids and Dynamic Items

Items created with a mutaplasmid (Abyssal modules) have attributes that differ
from their base item. Open the item detail page of such an item in your fit and
switch to the **Dynamic** tab to see the base item, the mutaplasmid used, and
every mutated attribute.

Each attribute row shows the base value and the mutation factor, so you can see
exactly how the roll turned out. The mutated values are what the fitting engine
uses everywhere in the fit's stats.

Use **Reroll** to randomize all attributes again within the mutaplasmid's
min/max range, or **Reset** to return every attribute to the base value. You
can also edit a single attribute's factor manually to model a specific roll.

See [Modules and Slots](efa://manual/fitting/modules) for fitting basics.
