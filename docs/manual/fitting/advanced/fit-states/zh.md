# 装配状态

配置中的每个装备和物品都有状态。装备在**上线**、**激活**、**超载**之间
循环：上线的装备已安装但未运行，激活的装备正在运行，超载的装备则带有
[装备超载](../overloading)中介绍的热量加成。

点击装备可将其状态向上切换，直到该装备支持的最高状态；超过最高状态后再
点击会回到**停用**状态。植入体和增效剂只能在启用与停用之间切换。

状态决定属性计算：只有激活的装备才会消耗电容并施加效果，而停用的植入体
和增效剂完全不产生任何作用。你可以通过切换状态来对比关键装备开启前后的
电容稳定性或伤害。

关于槽位基础，请参见[装备与槽位](efa://manual/fitting/modules)。
