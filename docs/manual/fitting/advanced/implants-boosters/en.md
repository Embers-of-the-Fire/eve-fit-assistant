# Implants and Boosters

Open the **Character** tab of a fit to manage implants and boosters. Implants go
into slots 1–10; each implant type occupies a fixed slot, and the app places it
automatically when you add it.

Pirate implant sets (such as Crystal or Snake) grant escalating bonuses as you
plug in more members of the set. Use the implant set dialog to apply a whole set
at once — sets are grouped by family and grade — and the app tracks set
membership so set effects are included in your stats.

Boosters occupy booster slots and provide strong temporary bonuses with possible
side effects, which the fitting engine models for you.

Implants and boosters can be switched between enabled and disabled states; see
[Fit States](../fit-states) for details.
