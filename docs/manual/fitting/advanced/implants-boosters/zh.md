# 植入体与增效剂

打开配置的**角色**标签页即可管理植入体和增效剂。植入体占用 1–10 号插槽，
每种植入体对应固定的插槽，添加时应用会自动放入正确位置。

海盗植入体套装（如水晶、天蛇）会随着植入套装成员数量的增加而提供递增的
套装加成。使用植入体套装对话框可以一次应用整套植入体——套装按系列和等级
分组展示——应用会跟踪套装成员关系，并将套装效果计入属性计算。

增效剂占用增效剂插槽，提供强力的临时加成，同时可能带有副作用，装配引擎
会为你建模这些效果。

植入体和增效剂可以在启用与停用状态之间切换，详见[装配状态](../fit-states)。
