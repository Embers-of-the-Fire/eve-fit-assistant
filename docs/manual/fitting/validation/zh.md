# 配置校验与问题报告

应用会持续校验你的配置，并在对应位置标注问题。装配页面的每个分区——
高槽、中槽、低槽、改装件、子系统、服务槽、无人机、舰载机、植入体与
增效剂——在出现问题时，其标题栏会显示警告或错误图标。

点击图标即可查看问题列表。问题分为两个级别：

- **错误**（红色）——配置无法按所示工作：物品类型未知或缺失、弹药尺寸
  或类型不匹配、炮台或发射器数量超限、装备互相冲突、改装件尺寸不符，
  或装备与该船体不兼容。
- **警告**（黄色）——配置可用但值得注意，例如武器未装填弹药。

每个问题都会标明受影响的槽位与位置，方便直接定位到问题装备。通过更换
或移除被标注的物品来解决问题——在错误修复之前，统计数值可能不准确。

导致这些错误的装配约束，见[装备与槽位](efa://manual/fitting/modules)。
