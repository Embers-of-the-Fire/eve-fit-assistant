# 装备与槽位

每个舰船配置都由槽位构成，每个槽位只能安装对应类型的装备：

- **高槽** —— 武器以及其他进攻或功能性装备。
- **中槽** —— 推进、电子战与护盾防御装备。
- **低槽** —— 火力、装甲与船体强化装备。
- **改装件槽** —— 永久性舰船改装，还会消耗校准值。

T3 巡洋舰额外拥有**子系统槽**。所选的四个子系统决定舰船最终拥有的
高、中、低槽数量。

建筑与旗舰还拥有**服务槽**，用于安装克隆、制造等勤务装备，仅在建筑
上线时可用。

装配受舰船 CPU 与能量栅格限制。若某件装备使任一资源超限，它将无法
上线——确定方案前请先查看装配用量条。

关于可切换模式的舰船，参见[战术模式](efa://manual/fitting/tactical-modes)；
关于让装备超负荷运转，参见[装备超载](efa://manual/fitting/advanced/overloading)。
