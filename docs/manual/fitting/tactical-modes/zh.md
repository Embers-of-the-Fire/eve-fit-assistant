# 战术模式

部分舰船——最典型的是 T3 驱逐舰——可以在多种战术模式之间切换。每种模式
都是不同的舰船形态：防御模式提升抗性，速度模式提升机动性与航速，狙击
（锁定）模式增加武器射程与追踪速度。

在装配页面，支持战术模式的舰船会在装备槽上方显示一行专属的模式槽。
点击该行即可切换到下一个模式；长按可查看该模式的详细属性。

切换模式会改变舰船的加成与属性，统计面板中的每秒伤害、防御和导航数值
会立即更新。所选模式会随配置一同保存。

槽位基础知识见[装备与槽位](efa://manual/fitting/modules)；如何解读各模式下
的数值见[属性与统计](efa://manual/fitting/attributes-stats)。
