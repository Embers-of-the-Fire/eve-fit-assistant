# Tactical Modes

Some hulls — most notably Tech 3 destroyers — can switch between tactical
modes. Each mode is a different ship configuration: defense mode boosts
resistances, speed mode improves agility and velocity, and targeting (sharpshooter)
mode extends weapon range and tracking.

On the fitting page, mode-capable ships show a dedicated tactical mode row
above the module slots. Tap the row to cycle to the next mode; long-press it
to inspect the mode's attributes.

Switching modes changes the ship's bonuses and attributes, so DPS, tank, and
navigation numbers in the stats panels update immediately. The selected mode
is saved with the fit.

See [Modules and Slots](efa://manual/fitting/modules) for slot basics and
[Attributes and Statistics](efa://manual/fitting/attributes-stats) for reading
the numbers each mode produces.
