# 存储空间管理

游戏数据文件在多个检出之间共享，因此保留多个数据版本通常比想象中更省空间。设置 → 数据 → 存储 会显示所有已安装检出占用的总大小和文件数量。

释放空间的方法：

- **删除不用的检出** —— 在 设置 → 数据 → 检出管理 中移除不再需要的旧数据版本。仍被其他检出使用的文件会被保留。
- **清理（Prune）** —— 设置 → 数据 → 存储 中的清理操作会扫描本地数据库，删除不再被任何检出引用的孤立文件。
- **清空全部存储** —— 删除所有已下载的数据和 HTTP 缓存。下次同步时应用需要重新下载数据，请仅在数据疑似损坏时作为最后手段使用。

清理和删除检出都不会影响你的配装、角色或设置——它们与游戏数据分开存储。
