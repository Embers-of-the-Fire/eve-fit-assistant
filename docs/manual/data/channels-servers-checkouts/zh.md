# 数据频道、服务器与检出

EVE Fit Assistant 不内置游戏数据，而是从远程**数据频道**（例如 `testing`）下载。首次启动应用时，你已经在[初始设置](efa://manual/getting-started/first-run-setup)中选择过一个频道。

每个频道包含一个或多个**服务器**（类似 TQ/SISI 的游戏环境）。每个服务器会发布多个**世代**——即某一时间点完整游戏数据（舰船、物品、技能、图标）的不可变快照。

下载到设备上的快照称为**检出**（数据版本）。你可以同时保留多个检出，但只有一个处于**激活**状态：装配器使用的所有舰船、物品和技能数据都来自它。

你可以在 设置 → 数据 → 频道元数据 中查看频道及其服务器，在 设置 → 数据 → 检出管理 中管理本地检出，包括切换激活的检出。

- 数据频道：你同步数据的远程来源。
- 服务器：频道内的一个游戏环境。
- 快照：服务器上发布的一个数据世代。
- 检出：下载到本地的快照；激活的检出让应用正常工作。
