# 检出历史与回滚

每个检出都保存着一份**历史记录**（reflog），记录它曾经指向过的所有快照——每次应用更新都会新增一条记录。你可以在 设置 → 数据 → 检出管理 → 历史 中查看这条时间线。

如果新数据版本引发了问题——例如配装无法打开或数据看起来不对——你可以执行**回滚**：在历史记录中选择更早的一条，将检出恢复到该快照。由于旧数据仍保存在本地，回滚无需重新下载全部内容。

回滚是安全且可逆的。之后再次更新只会把检出推进到最新快照，并在历史中再记录一条。

注意，回滚改变的是数据版本，而不是你的配装——已保存的配装单独存储，不会因回滚数据而被修改。

- 设置 → 数据 → 检出管理 → 点击检出上的历史图标。
- 选择一个较早的快照并确认回滚。
- 当新更新引发问题时先回滚，等修复发布后再更新。
