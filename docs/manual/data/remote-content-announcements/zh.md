# 公告与远程内容

除了游戏数据，你的数据频道还会推送**公告**——来自 EVE Fit Assistant 团队的更新日志和新闻。部分公告随应用内置，更新的公告则在应用同步时作为远程内容送达。

你可以在 设置 → 版本 → 更新日志 中阅读公告列表。未读公告会以角标显示数量，点击任意一条即可查看全文。

公告按页面组织；如果某条公告延续到其他页面，可通过详情页底部的链接继续阅读。

本手册同样是应用内容的一部分：它随应用打包，因此可以离线阅读。更新版手册随应用更新一同送达，远程内容管道不会刷新手册。

- 设置 → 版本 → 更新日志 → 带未读角标的公告列表。
- 公告有两个来源：应用内置与远程获取。
- 内置手册支持离线阅读，随应用版本更新。
