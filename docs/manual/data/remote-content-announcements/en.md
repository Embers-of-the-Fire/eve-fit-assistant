# Announcements & Remote Content

Besides game data, your channel also delivers **announcements** — release notes and news from the EVE Fit Assistant team. Some announcements are bundled with the app; newer ones arrive as remote content when the app syncs.

You can read the announcement feed from Settings → Version → Release Notes. A badge shows how many entries you have not read yet, and tapping an entry opens its full text.

Announcements are organized into pages; if an entry continues on another page, follow the link at the bottom of the detail view.

This manual is also part of the app's content: it is bundled with the app so it works offline, and can be refreshed through the same remote content pipeline when updated editions are published.

- Settings → Version → Release Notes → announcement feed with unread badge.
- Announcements come from two sources: bundled with the app and fetched remotely.
- The built-in manual works offline and updates through the same channel.
