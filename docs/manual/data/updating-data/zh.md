# 更新数据

应用会定期检查你所用数据频道是否有新数据。当有新快照可用时，[工作台](efa://manual/getting-started/workspace)会显示更新横幅，设置 → 数据 中也会出现更新入口。

应用更新时只会下载发生变化的文件——设备上已有的相同文件会被复用，因此更新通常很小、很快。

更新是原子性的：只有当所有文件下载并校验完成后，新数据版本才会生效。如果下载被中断（网络断开、应用关闭），不会造成任何损坏——残留的不完整文件会在下次启动时自动清理，你只需重试更新即可。

下载完成后，更新后的检出会成为激活的数据版本。你的配装和角色数据不受影响。

- 工作台上的更新横幅 → 点击「更新」开始。
- 设置 → 数据 → 检出管理 → 更新单个检出。
- 中断的下载会在下次启动应用时自动恢复清理。
