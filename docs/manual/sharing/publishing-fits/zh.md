# 发布配置

发布会将配置上传到 EFA Platform（`platform.efa-tech.dev`）并为其创建一个公开的**帖子**：任何人都可以在浏览器中打开该页面，查看带舰船详情的交互式配置快照；登录用户还可以在讨论区发表 Markdown 评论。帖子与发布账号关联，发布者可以在帖子页面删除自己的帖子；版主可以删除任意帖子。

发布是唯一会把配置数据上传到服务器的功能——除此之外配置都保存在你的设备本地。

## 前提条件

发布需要已登录的平台账号，并且账号具有发布权限（每个账号默认都有）。详见[账号](efa://manual/pages/settings/account)。只有在已登录且具备权限时，**分享**操作才会显示。

平台还必须已收录应用当前使用的数据快照；如果尚未收录，发布会失败并提示错误，请稍后重试。

## 分享配置

在[配置列表](efa://manual/pages/home/fit-list)中向右滑动条目，点按**分享**。分享对话框会显示配置名称，点按**分享**即可发布。

平台会对完全相同的配置去重：如果相同配置已被发布过，会直接复用已有帖子，而不会创建新帖子。无论哪种情况，对话框都会显示结果，并在浏览器中打开帖子页面。如果无法打开页面，可以改用对话框中的**复制链接**复制帖子地址。

发布失败——登录状态失效、缺少发布权限、数据仓库尚未就绪、平台尚未收录当前数据快照、平台拒绝或无法识别配置中的物品、网络错误——都会在对话框中显示对应的提示。
