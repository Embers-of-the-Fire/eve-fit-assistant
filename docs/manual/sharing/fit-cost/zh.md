# 配置估价

了解一套配装在市场上的大致价格。

估价总额显示在配装属性面板的末尾。长按价格可打开明细页面，逐项查看每件物品的数量、卖单单价与买单单价，以及卖单与买单总额。卖单总额即买入整套配装所需的花费；买单总额即整套卖出可获得的收入。

估价涵盖配装中的所有内容：船体、全部已装配的装备及其弹药、无人机、舰载机、植入体与增效剂。变异（动态）装备按其最终物品类型计价。

价格来自与你的游戏数据关联的市场服务器——晨曦（Serenity）或宁静（Tranquility）——数据由 ceve-market.org 提供。如果数据源未声明市场服务器，可在应用设置中指定回退服务器；否则该功能不会显示。

没有可用价格的物品会被静默排除在总额之外，因此此时的估价可能偏低。明细页面会标明有多少种物品未能取得价格。
