# 导出配置

将已保存的配装转换为可随处粘贴的文本。

在配装页面打开导出对话框，选择格式后，点击**复制**将文本放入剪贴板，或点击**分享**通过系统分享面板发送。

提供两种格式：

- **原生格式** —— 紧凑的 `EFA2:` 字符串，完整保留配装，包括变异（动态）装备。与其他 EVE Fit Assistant 用户分享时请使用此格式；对方可直接粘贴到[导入对话框](efa://manual/sharing/importing-fits)。
- **EFT 格式** —— 经典的 `[舰船名, 配置名]` 文本格式，使用英文物品名称，EVE 客户端和大多数第三方工具均可识别。

EFT 导出是有损的：该格式无法表达的细节会被丢弃，选中此格式时对话框会显示警告。双方都使用本应用时，请优先选择原生格式。

另请参阅[创建你的第一个配置](efa://manual/getting-started/create-first-fit)。
