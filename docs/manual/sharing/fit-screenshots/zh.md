# 配置截图

将配装渲染为一张可保存或分享的图片。

在配装页面打开截图视图。应用会将配装排版成海报样式：一栏显示植入体与增效剂，一栏显示全部装备（高/中/低槽、改装件、子系统、服务槽、无人机与舰载机），第三栏显示舰船属性——电容、武器、防御与货舱等。

点击**保存**，图片会以 PNG 文件写入下载文件夹，文件名由配置名称加时间戳组成。

点击**分享**，可直接通过系统分享面板将图片发送给其他应用或联系人。

图片会按设备像素密度以高分辨率渲染，发布或放大后依然清晰。配装及其计算属性完全加载后才能生成截图。
