# 导入配置

使用导入对话框将文本形式的配装带入应用。

打开导入对话框，将配装字符串粘贴到文本框中，或点击粘贴按钮从剪贴板自动填入。点击导入确认；成功后配装会被保存并直接打开。

支持两种文本格式：

- **原生格式** —— 以 `EFA:` 或 `EFA2:` 开头的字符串，由本应用的[导出对话框](efa://manual/sharing/exporting-fits)生成，可无损保留完整配装。
- **EFT 格式** —— 以 `[舰船名, 配置名]` 开头的经典文本格式，与 EVE 客户端及许多第三方工具兼容。

游戏内的 `fitting:` 链接不受支持，会被拒绝。

如果文本无法解析，对话框中会显示错误提示，且不会导入任何内容。常见原因包括输入为空、格式无法识别、物品或舰船名称未知，或当前游戏数据中不存在该舰船。修正文本后重试即可。

刚开始配装？请参阅[创建你的第一个配置](efa://manual/getting-started/create-first-fit)。
