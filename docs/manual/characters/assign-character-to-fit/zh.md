# 为配装指派角色

每份配装都使用一个角色，其技能等级驱动配装的所有计算属性——伤害、防御、电容，以及属性面板上的其他一切数值。新建配装默认使用内置的全 V 档案。

要更换角色，打开配装并切换到角色标签页。顶部一行显示当前角色，点击它会打开选择器，列出内置档案和你的所有自定义档案。切换角色后，配装属性会立即重新计算。

技能来自角色，但植入体和增效剂保存在配装本身——更换角色时它们保持不变。角色标签页内还有植入体和增效剂两个子标签，参见[植入体与增效剂](efa://manual/fitting/advanced/implants-boosters)。

由于角色是共享的，在角色上修改技能等级会更新所有使用该角色的配装。如果你想比较不同技能水平下的配装（例如模拟主力的 Alpha 克隆体），可以创建多个角色分别指派。

关于技能如何影响各项计算属性，参见[属性与面板](efa://manual/fitting/attributes-stats)。
