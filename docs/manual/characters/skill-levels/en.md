# Setting Skill Levels

Open a character and switch to the skills tab to edit its trained skills. The full EVE skill list is shown, filtered by skill group.

Tap the group filter bar at the top to expand a grid of skill groups (Gunnery, Missiles, Spaceship Command, and so on) and pick one to narrow the list. Tap the selected group again to show all groups.

Each skill row has five level pips. Tap a pip to train the skill to that level; tapping the pip of the current level resets the skill to untrained (level 0). Tap or long-press the skill name to open its item detail page.

Levels beyond an Alpha clone's maximum are shown in a limited color, so you can see at a glance what an Alpha pilot cannot train.

There is no one-tap "all skills at V" button for custom characters. To start from everything at V, clone the built-in All V profile on the character page and lower the skills your pilot has not trained. See [Managing Characters](efa://manual/characters/managing-characters).
