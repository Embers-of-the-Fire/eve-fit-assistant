# 设置技能等级

打开一个角色并切换到技能标签页即可编辑其已训练的技能。页面会显示完整的 EVE 技能列表，并可按技能分组筛选。

点击顶部的分组筛选栏，展开技能分组网格（炮术、导弹、飞船指挥等），选择一个分组即可缩小列表范围；再次点击已选中的分组则恢复显示全部分组。

每行技能有五个等级圆点。点击某个圆点即可将技能训练到对应等级；点击当前等级的圆点会将技能重置为未训练（0 级）。点击或长按技能名称可打开其物品详情页。

超出 Alpha 克隆体上限的等级会以受限颜色显示，方便你一眼看出 Alpha 飞行员无法训练的部分。

自定义角色没有一键"全 V"按钮。如果想从全 V 起步，请在角色页面克隆内置的全 V 档案，再把飞行员未训练的技能调低。参见[管理角色](efa://manual/characters/managing-characters)。
