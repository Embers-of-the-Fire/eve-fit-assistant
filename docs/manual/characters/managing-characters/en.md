# Managing Characters

A character in EVE Fit Assistant is a named skill profile: a set of trained skill levels that drives the computed stats of any fit that uses it.

Open the character page to see two sections. Built-in profiles — All V, Alpha Max, and All 0 — are always available and cannot be edited or deleted. Your custom profiles appear below; tap the add button in the section header to create one.

Custom characters can be renamed and given a description on the profile info tab of the character editor. Swipe a profile in the list to edit or delete it; deletion asks for confirmation.

You can also clone any profile, including the built-in ones. Cloning All V is the quickest way to start a custom character with every skill already at level V, then trim it down to match your real pilot.

Characters are reusable: any number of fits can share the same character, so updating a skill level updates every fit that uses it.
