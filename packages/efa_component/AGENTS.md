# efa_component

Scope: shared presentational Flutter widgets for EVE Fit Assistant surfaces, including
packaged image/icon assets.

- Keep widgets presentational and reusable; feature state and storage orchestration belong in
  the consuming app/package.
- Follow @docs/agents/style and @docs/agents/color for visual changes.
- Keep assets referenced by `pubspec.yaml` in sync when adding or removing files.

Validation: run the relevant Dart formatter/analyzer and package tests when present.
