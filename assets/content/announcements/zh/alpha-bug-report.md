# Alpha 测试阶段错误报告指南

本公告包含了在 Alpha 测试阶段报告错误的指南和建议，
以帮助我们更快地识别和解决问题。

## 报告错误的步骤

你可以选择如下任一方式进行报告（按照习惯优先级排序）：

1. 通过 [Github](https://github.com/Embers-of-the-Fire/eve-fit-assistant/issues) 提交一个新的 Issue。
2. 通过官方 QQ 群聊 1031146601（EFA Official）直接联系开发者。
3. 通过友好 QQ 群聊 611597125（EVE空间站 5 群）直接联系开发者。

## 如何提供有用的错误报告

### 通过 Github 提交 Issue

Github 提供了双语版本的 issue 模板，请按照模板内容操作。

### 通过 QQ 联系开发者

请你**直接私聊**开发者，不要通过在群聊内 ping 或者添加
私人好友的方式联系开发者，以免打扰其他成员。

私聊时请提供以下信息：

- 你的操作系统版本（例如 Windows 10, macOS 12.3 等）。
- 你使用的 EFA 版本（例如 v0.1.0-alpha）。
- 错误发生的具体步骤（例如 "我点击了导入按钮，然后选择了一个文件，之后应用崩溃了"）。
- 错误的数据包。
- 错误的截图或者录屏（如果可能的话）。
