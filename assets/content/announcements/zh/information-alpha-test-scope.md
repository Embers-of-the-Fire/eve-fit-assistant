# Alpha 测试说明

这份说明用于帮助测试者快速了解当前 Alpha 构建已支持的流程、仍然存在的限制，以及在数据上下文不一致时推荐的恢复方式。

## 建议优先测试

- 导入或安装数据包，并有意识地切换当前活动数据包。
- 创建配置、检查属性结果，并测试导出或分享流程。
- 继续验证仍在 Alpha 范围内的高级装配：弹药、铁骑舰载机与子系统。

## 当前限制

- 工作台中的"更新动态"列表会混合显示公告、信息说明和版本日志；请通过每张卡片上的标签区分内容类型。
- 应用同一时间只会激活一个数据包。若配置保存时使用的是其他数据包，它仍可查看，但会保持只读，直到切回原数据包或重新导入所需数据包。
- 深渊物品转换不在当前 Alpha 范围内。已有的深渊物品仍可打开并还原。
- 原生文本导入目前接受 `EFA:` 和 `EFA1:` 两种前缀；更高版本的显式前缀会在支持对应载荷版本前被拒绝。

## 恢复建议

- 如果切换数据包后某个配置变成只读，且原数据包仍已安装，请到数据包管理中切回该数据包。
- 如果原数据包已缺失，请先重新导入对应数据包，再继续编辑该配置。
- 如果你本来就想把配置迁移到当前数据包，请先导出配置，确认目标数据集后，再以新副本的方式重新导入。
