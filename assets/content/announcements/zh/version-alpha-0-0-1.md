# 版本 Alpha 0.0.1

## 新增

- 新增启动公告弹窗，支持"不要再显示"和跳转查看详情。
- 新增本地角色技能档案，可以创建、复制、编辑和删除自定义档案。
- 新增 Alpha Max 内置技能档案，并在技能列表中标记 Alpha 克隆限制等级。
- 配置页的角色页现在可以按技能组浏览技能，并直接点选技能等级。
- 装配的角色页现在可以为每套配置选择内置或自定义技能档案。
- 物品详情新增深渊属性页，支持查看基础物品、突变质体、重置、随机重掷和手动编辑属性值。
- 装配槽位新增深渊转换与还原入口，并改进弹药选择、子系统替换和铁骑舰载机相关流程。

## 改进

- 装配页在数据包切换、缺失或版本不匹配时会显示更明确的只读提示、恢复操作和加载遮罩。
- 物品详情中的属性值现在会按 Dogma 单位格式化，距离、时间、百分比、体积、尺寸和性别等单位更易读。
- 物品详情会隐藏不可用的当前属性值，避免把缺失计算结果误读为真实数值。
- 数据包管理器会说明 Alpha 阶段只能全局启用一个数据包，并在切换时展示待加载状态。
- 启动时的本地持久化修复提示更具体，会说明恢复的配置、数据包和无法读取的文件数量。

## 架构

- 数据包加载改为更安全的事务式状态管理，旧数据包会在新数据包加载失败时保持可用。
- 数据包导入支持增量包、删除文件清单、补丁历史和 manifest hash 校验。
- 生成数据中加入 Alpha 克隆技能上限和 Dogma 单位 ID 常量，供技能档案和单位格式化复用。
- 文档系统支持启动公告状态，并修复了 Alpha 错误报告文档的 `tags` 元数据。
