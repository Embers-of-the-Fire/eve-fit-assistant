# Welcome to the document center

This release adds a dedicated place for announcements and version notes.

## What is available now

- Bundled announcement entries that ship inside the app binary.
- Bundled version changelog entries available from Settings.
- A shared document layout that is ready for mixed feeds and future remote updates.

## What comes next

The storage format already leaves room for online updates, cached remote documents, and migration-safe schema changes without mixing them into the bundled defaults.
