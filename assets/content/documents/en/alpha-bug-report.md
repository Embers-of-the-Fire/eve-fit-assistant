# Alpha Testing Bug Report Guide

This announcement contains guidelines and suggestions for reporting bugs during the Alpha
testing phase, helping us identify and resolve issues more quickly.

## Steps to Report a Bug

You can choose any of the following methods to report a bug (listed in order of preferred
priority):

1. Submit a new issue through
   [GitHub](https://github.com/Embers-of-the-Fire/eve-fit-assistant/issues).
2. Contact the developers directly through the official QQ group chat 1031146601
   (EFA Official).
3. Contact the developers directly through the community QQ group chat 611597125
   (EVE Space Station Group 5).

## How to Provide a Useful Bug Report

### Submitting an Issue Through GitHub

GitHub provides bilingual issue templates. Please follow the template when reporting a bug.

### Contacting Developers Through QQ

Please contact the developers **via direct message**. Do not ping them in the group chat or
add them as personal friends, so other members are not disturbed.

When sending a direct message, please provide the following information:

- Your operating system version (for example, Windows 10 or macOS 12.3).
- The version of EFA you are using (for example, v0.1.0-alpha).
- The exact steps that caused the bug (for example, "I clicked the import button, selected a
  file, and then the app crashed.").
- The bug data package.
- A screenshot or screen recording of the bug, if possible.
