# Security Policy

## Reporting a Vulnerability

If you believe you have discovered a security vulnerability in EVE Fit Assistant,
please report it to us privately. **Do not open a public GitHub issue.**

### Contact Channels

- **Email:** [security@efa-tech.dev](mailto:security@efa-tech.dev)
  Please use the subject prefix `[EFA/Security]` so your report is routed
  appropriately.
- **QQ:** `3562377918`

### Disclosure Timeline

- We aim to acknowledge your report within **5 business days**.
- We will disclose the vulnerability:
  - **30 days** after the fix is released, if the vulnerability does not
    originate in the application itself.
  - **90 days** after the fix is released, if the vulnerability originates
    in the application.

### What to Include

To help us triage quickly, please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce, including environment details (OS version, app version,
  data bundle version).
- Any relevant logs, screenshots, or proof-of-concept code.

We appreciate your help in keeping EFA and its users safe.
